# Q007：スコープとクロージャのコード読解

## 条件

- 資料を見ないで回答してください。
- コードを実行しないでください。
- A〜Eについて、出力または発生するエラーを答えてください。
- 各回答に短い理由を付けてください。

## 問題

```js
const label = "global";

function createCounter(start) {
  let count = start;

  return function increment() {
    count += 1;
    return count;
  };
}

function showLabel() {
  const label = "local";
  return label;
}

const counterA = createCounter(0);
const counterB = createCounter(10);

console.log("A", counterA());
console.log("B", counterA());
console.log("C", counterB());
console.log("D", showLabel());
console.log("E", label);
```
