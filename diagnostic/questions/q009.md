# Q009：DOM・イベント・API通信

## 条件

- AI、検索、書籍、既存コードを参照しないでください。
- 実行しなくて構いません。
- 完成できない場合も、分かる行だけ書いてください。

## HTML

```html
<form id="user-form">
  <input id="user-id" />
  <button type="submit">検索</button>
</form>

<p id="result"></p>
```

## 問題

上のHTMLに対して、次の動作を実装するJavaScriptを書いてください。

1. フォームが送信されたら、ページの再読み込みを止める
2. `#user-id`へ入力された値を取得する
3. `https://example.com/api/users/入力値`へ`fetch`でGETリクエストを送る
4. HTTPレスポンスが成功でなければ、エラーとして扱う
5. 成功時はJSONを読み取り、その`name`を`#result`へ表示する
6. 失敗時は`ユーザーを取得できませんでした`と`#result`へ表示する
7. APIから取得した文字列をHTMLとして解釈させない
