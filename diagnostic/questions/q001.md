# Q001：値・型・参照のコード読解

## 条件

- 資料を見ないで回答してください。
- このコードを実行しないでください。
- 各出力について、値だけでなく、その結果になる理由を1〜2文で説明してください。
- エラーになると考える箇所があれば、出力の代わりにエラーの種類と発生理由を書いてください。

## 問題

次のコードにある `A`〜`H` の出力を、上から順に答えてください。

```js
const original = {
  name: "  Alice  ",
  scores: [80, 90],
  options: {
    notify: false,
  },
};

const copied = {
  ...original,
  name: original.name.trim(),
};

copied.scores.push(100);
copied.options.notify = true;

const inputCount = "0";
const parsedCount = Number(inputCount);

console.log("A", original.name === copied.name);
console.log("B", original.scores.length);
console.log("C", original.options.notify);
console.log("D", original === copied);
console.log("E", original.scores === copied.scores);
console.log("F", Boolean(inputCount));
console.log("G", parsedCount || 10);
console.log("H", parsedCount ?? 10);
```

最後に、`original`のネストした値を変更せずに、次の`copied`を作るにはどこを直すべきか、コードで示してください。

- `copied.name`は前後の空白を除く
- `copied.scores`には`100`を追加する
- `copied.options.notify`は`true`にする
- `original`はどの階層も変更しない
