# Q008：非同期処理とエラー処理

## 条件

- 資料を見ないで回答してください。
- コードを実行しないでください。
- A〜Eがコンソールへ表示される順番と、それぞれの表示内容を答えてください。
- 最後の質問にも短く回答してください。

## 問題

```js
function getScore() {
  return Promise.resolve(80);
}

async function showScore() {
  try {
    console.log("B");
    const score = await getScore();
    console.log("C", score);
    throw new Error("failed");
  } catch (error) {
    console.log("D", error.message);
  }
}

console.log("A");
showScore();
setTimeout(() => {
  console.log("E");
}, 0);
```

### 質問1

コンソールに表示される順番と内容を、1行ずつ書いてください。

### 質問2

`showScore()`の戻り値は、どのような種類の値ですか。

### 質問3

`getScore()`がrejectされた場合、上のコードではどこで処理されますか。
