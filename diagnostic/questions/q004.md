# Q004：条件に合うユーザーのIDを取り出す

## 条件

- AI、検索、書籍、既存コードを参照しないでください。
- コードは実行して構いません。
- `filter`と`map`は使わず、ループと`if`を使ってください。
- 元の配列とオブジェクトを変更しないでください。

## 問題

ユーザーの配列を受け取り、`isActive`が`true`のユーザーの`id`だけを、新しい配列で返す`getActiveUserIds(users)`を実装してください。

```js
const users = [
  { id: 1, name: "Alice", isActive: true },
  { id: 2, name: "Bob", isActive: false },
  { id: 3, name: "Carol", isActive: true },
];

getActiveUserIds(users); // [1, 3]
```

空配列を受け取った場合は、空の配列を返してください。
