# Q005：商品名の抽出

## 条件

- AI、検索、書籍、既存コードを参照しないでください。
- コードは実行して構いません。
- `for`、`while`、`forEach`は使わないでください。
- `filter`と`map`の両方を使ってください。
- 元の配列とオブジェクトを変更しないでください。

## 問題

商品の配列と最低価格を受け取り、次の条件を満たす`getAvailableProductNames(products, minimumPrice)`を実装してください。

1. `inStock`が`true`の商品だけを対象にする
2. `price`が`minimumPrice`以上の商品だけを対象にする
3. 条件に合う商品の`name`だけを新しい配列で返す
4. 商品の順番は入力時の順番を維持する

```js
const products = [
  { id: 1, name: "Keyboard", price: 8000, inStock: true },
  { id: 2, name: "Mouse", price: 3000, inStock: false },
  { id: 3, name: "Monitor", price: 30000, inStock: true },
  { id: 4, name: "Cable", price: 1000, inStock: true },
];

getAvailableProductNames(products, 5000);
// ["Keyboard", "Monitor"]
```

条件に合う商品がない場合と、入力が空配列の場合は、空配列を返してください。
