# Q006：文字列を整えて新しいオブジェクトを作る

## 条件

- AI、検索、書籍、既存コードを参照しないでください。
- コードは実行して構いません。
- 入力された`user`オブジェクトを変更しないでください。
- スプレッド構文を使う必要はありません。

## 問題

ユーザーオブジェクトを受け取り、次の形式の新しいオブジェクトを返す`formatUser(user)`を実装してください。

- `id`は入力された値をそのまま使用する
- `displayName`は、`firstName`と`lastName`それぞれの前後の空白を削除し、間に半角スペースを1つ入れる
- `email`は前後の空白を削除し、すべて小文字にする

```js
const user = {
  id: 10,
  firstName: "  Taro",
  lastName: "Yamada  ",
  email: "  TARO@EXAMPLE.COM ",
};

formatUser(user);
// {
//   id: 10,
//   displayName: "Taro Yamada",
//   email: "taro@example.com",
// }
```
