## 問題

次の仕様を満たす関数`createActiveUserSummaries(users)`を実装してください。

1. `isActive`が`true`のユーザーだけを対象にする
2. `name`の前後の空白を削除する
3. 各ユーザーの`scores`から平均点を計算する
   - `scores`が空配列の場合、平均点は`0`
4. 次の形の新しいオブジェクトへ変換する

```js
{
  id: 1,
  name: "Alice",
  averageScore: 85,
}
```

5. `averageScore`の高い順に並べる
6. 平均点が同じ場合は`id`の小さい順に並べる
7. 元の配列・オブジェクト・`scores`配列を変更しない

## 入力例

```js
const users = [
  {
    id: 1,
    name: "  Alice ",
    isActive: true,
    scores: [80, 90],
  },
  {
    id: 2,
    name: "Bob",
    isActive: false,
    scores: [100, 100],
  },
  {
    id: 3,
    name: " Carol  ",
    isActive: true,
    scores: [],
  },
  {
    id: 4,
    name: "Dave",
    isActive: true,
    scores: [90, 80],
  },
];
```

## 期待結果

```js
[
  { id: 1, name: "Alice", averageScore: 85 },
  { id: 4, name: "Dave", averageScore: 85 },
  { id: 3, name: "Carol", averageScore: 0 },
]
```
