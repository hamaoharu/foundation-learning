# Q003 採点結果

## 結果

入力例3件は、いずれも戻り値が`undefined`となりました。

## できていたこと

- 合計用変数を`0`で初期化できている
- 配列の長さを使った`for`ループを書けている
- `numbers[i]`で各要素を取得できている
- `+=`で合計を累積できている
- 空配列ではループを実行せず、合計が`0`のままになる構成を作れている

## 修正点

計算した`sum`を関数の呼び出し元へ返す処理がありません。

```js
function sumNumbers(numbers) {
  let sum = 0;

  for (let i = 0; i < numbers.length; i++) {
    sum += numbers[i];
  }

  return sum;
}
```

## 暫定所見

- ループと配列の基本操作：理解あり
- 累積処理：理解あり
- 関数の戻り値：知識は既習と考えられるが、実装時に抜けるため不安定
- 問題文の「返す」をコード上の`return`へ変換する確認習慣が必要
