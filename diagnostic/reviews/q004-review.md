# Q004 初回採点結果

## テスト結果

- 通常ケース：不正解
- 空配列：正解
- アクティブユーザーがいないケース：正解
- 元データの非変更：問題なし

## できていたこと

- 新しい配列を用意できている
- `for`ループで全ユーザーを確認できている
- `if`でアクティブユーザーだけを選べている
- `push`で結果を追加できている
- 結果を`return`できている
- 該当者がいない場合に空配列を返せている

## 修正点

仕様はユーザーオブジェクトではなく、ユーザーの`id`だけを返すものです。

現在の処理：

```js
activeUsers.push(users[i]);
```

必要な処理：

```js
activeUserIds.push(users[i].id);
```

また、`isActive`はすでにbooleanなので、次のように直接条件にできます。

```js
if (users[i].isActive) {
```

`== true`でも今回の入力では判定できますが、暗黙的型変換を行う`==`は通常避けます。明示的に比較する必要がある場合は`===`を使います。

## 暫定所見

- ループ・条件分岐・配列追加・return：基本実装ができる
- オブジェクトのプロパティ参照：条件判定では使えている
- 問題文の出力形式をコードへ反映する工程：不安定
- `==`と`===`の選択：追加確認が必要
