# Q007 採点結果

## 正解

```text
A 1
B 2
C 11
D local
E global
```

## 採点

- A：正解
- B：不正解（回答は`1`、正解は`2`）
- C：正解
- D：正解
- E：正解

## Bが`2`になる理由

`createCounter(0)`を呼ぶと、その呼び出し専用の`count`が作られます。返された`increment`関数は、呼び出し終了後もその`count`を参照し続けます。

```js
counterA(); // count: 0 -> 1
counterA(); // 同じcount: 1 -> 2
```

`counterB`は別の`createCounter(10)`呼び出しで作られたため、別の`count`を保持します。

このように、関数が定義された場所の外側の変数を保持して利用できる仕組みがクロージャです。

## 暫定所見

- ブロック外／関数内の名前解決：基礎理解あり
- クロージャによる状態保持：理解が曖昧
- 高階関数（関数を返す）：理解が曖昧
