## `parseInt`と`Number`の違い

今回の入力ではどちらでも正解になりますが、目的が異なります。

```js
Number("20px");   // NaN
parseInt("20px"); // 20

Number("10.5");   // 10.5
parseInt("10.5"); // 10
```

- `Number`：入力全体を数値として変換する
- `parseInt`：先頭から整数として読み取れる部分を取得する

フォームの値を通常の数値として扱う今回のような問題では、意図が明確な`Number(ageInput)`を基本とします。
