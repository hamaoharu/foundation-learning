# Unit 2 / Q007 初回採点結果

## 判定

不正解。修正と類題確認が必要。

## 現在のコード

```js
return name && "ゲスト";
```

`&&`は左側がtruthyなら右側を返し、左側がfalsyなら左側を返します。

```js
"Alice" && "ゲスト"; // "ゲスト"
"" && "ゲスト";      // ""
```

今回必要なのは、左側がtruthyなら名前を維持し、falsyなら既定値を返す処理です。この動作をするのは`||`です。

```js
"Alice" || "ゲスト"; // "Alice"
"" || "ゲスト";      // "ゲスト"
```

## 新単元の所見

- 個別の出力予測では`&&`と`||`を正しく判断できた
- 要件から適切な演算子を選んで実装する段階では混同がある
- 修正後、別の類題で自力実装を確認する

## 修正結果

`return name || "ゲスト";`へ修正し、4ケースすべて合格。
ただし解説直後の修正であるため、類題Q008で定着を確認する。
