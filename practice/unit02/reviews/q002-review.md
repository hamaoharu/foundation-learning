# Unit 2 / Q002 採点結果

## 判定

8問すべて正解。

## 正解

- `Boolean(0)` → `false`
- `Boolean("0")` → `true`
- `Boolean("")` → `false`
- `Boolean(" ")` → `true`
- `Boolean(null)` → `false`
- `Boolean(undefined)` → `false`
- `Boolean([])` → `true`
- `Boolean({})` → `true`

## 確認できたこと

- 数値`0`と文字列`"0"`を区別できる
- 空文字と空白を含む文字列を区別できる
- `null`と`undefined`がfalsyだと理解している
- 空であっても配列とオブジェクトはtruthyだと理解している
