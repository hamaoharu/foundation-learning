# Unit 2 / Q005：文字列の価格を合計する

## 問題

フォームから受け取った2つの価格を想定した文字列`firstPrice`と`secondPrice`を受け取り、数値として合計した結果を返す`calculateTotal`を実装してください。

- 両方の入力を`Number()`で数値へ変換する
- 変換後の2つの数値を加算する
- 合計を数値としてreturnする

```js
calculateTotal("100", "50");   // 150
calculateTotal("1000", "500"); // 1500
calculateTotal("0", "20");     // 20
```

空文字や数字以外の入力は、今回は考えなくて構いません。
