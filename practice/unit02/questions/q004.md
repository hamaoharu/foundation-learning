# Unit 2 / Q004：文字列の年齢を数値に変換する

## 問題

フォームから受け取った年齢を想定した文字列`ageInput`を受け取り、次のメッセージを返す`getAgeMessage`を実装してください。

- `ageInput`を数値へ明示的に変換する
- 変換後の年齢が18以上なら`"成人"`を返す
- 18未満なら`"未成年"`を返す

```js
getAgeMessage("20"); // "成人"
getAgeMessage("18"); // "成人"
getAgeMessage("17"); // "未成年"
getAgeMessage("0");  // "未成年"
```

空文字や数字以外の入力は、今回は考えなくて構いません。
