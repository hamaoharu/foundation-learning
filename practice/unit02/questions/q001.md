## 問題

次のA〜Dの評価結果を`true`または`false`で答え、短い理由を書いてください。コードは実行しないでください。

```js
const input = "10";
const count = 10;

console.log("A", input === count);
console.log("B", Number(input) === count);
console.log("C", String(count) === input);
console.log("D", input !== String(count));
```
