# Unit 2 / 追加確認Q001：テーマの既定値

## 問題

設定画面から受け取ったテーマ名を想定した文字列`theme`を受け取り、次のルールで値を返す`getTheme`を実装してください。

- `theme`が空文字なら`"light"`を返す
- それ以外なら`theme`をそのまま返す
- 条件分岐文は使わず、1つのreturn文で実装する

```js
getTheme("dark"); // "dark"
getTheme("");     // "light"
getTheme("0");    // "0"
```

どの演算子を使うかは自分で判断してください。
