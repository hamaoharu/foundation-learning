# Unit 2 / Q006：入力の有無をbooleanで返す

## 問題

フォーム入力を想定した文字列`input`を受け取り、その値を`Boolean()`で変換して返す`hasInput`を実装してください。

```js
hasInput("Alice"); // true
hasInput("");      // false
hasInput("0");     // true
hasInput(" ");     // true
```

空白を削除する処理は、今回は行いません。
