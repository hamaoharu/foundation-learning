# Unit 2 / Q007：表示名の既定値

## 問題

文字列`name`を受け取り、次のルールで表示名を返す`getDisplayName`を実装してください。

- `name`が空文字なら`"ゲスト"`を返す
- それ以外なら`name`をそのまま返す
- `||`を使って1つのreturn文で実装する

```js
getDisplayName("Alice"); // "Alice"
getDisplayName("");      // "ゲスト"
getDisplayName("0");     // "0"
getDisplayName(" ");     // " "
```

空白を削除する処理は、今回は行いません。
