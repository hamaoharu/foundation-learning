# Unit 1 / 完了確認Q001：送料を返す

## 問題

注文金額`amount`と、プレミアム会員かどうかを表す`isPremium`を受け取り、送料を返す`calculateShippingFee`を実装してください。

- プレミアム会員なら、注文金額に関係なく送料は`0`
- プレミアム会員ではなく、注文金額が`5000`以上なら送料は`0`
- それ以外は送料`500`

```js
calculateShippingFee(1000, true);   // 0
calculateShippingFee(5000, false);  // 0
calculateShippingFee(4999, false);  // 500
```

## 条件

- 資料を参照せず実装してください
- 実装方法は自由です
- コードは実行して構いません
