# Unit 1 / Q001：税込価格を返す

## 問題

商品価格`price`と税率`taxRate`を受け取り、税込価格を返す`calculatePriceWithTax`を実装してください。

```js
calculatePriceWithTax(1000, 0.1); // 1100
calculatePriceWithTax(500, 0);    // 500
```

小数の丸め処理は不要です。

## 実装前にコメントで書くこと

1. 入力される値 価格　税率
2. 戻す値　税込価格
3. 計算手順　価格に税率に１足したものをかける
