# Unit 1 / Q003：点数から評価を返す

## 問題

0〜100の点数`score`を受け取り、次のルールで評価を返す`getGrade`を実装してください。

- 80以上：`"A"`
- 60以上80未満：`"B"`
- 60未満：`"C"`

```js
getGrade(100); // "A"
getGrade(80);  // "A"
getGrade(79);  // "B"
getGrade(60);  // "B"
getGrade(59);  // "C"
getGrade(0);   // "C"
```

0未満や100を超える入力は、今回は考えなくて構いません。

## 実装前にコメントで書くこと

1. 入力される値
2. 戻す値
3. 条件を確認する順番
