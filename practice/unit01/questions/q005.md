# Unit 1 / Q005：会員価格を返す

## 問題

価格`price`、割引率`discountRate`、会員かどうかを表す`isMember`を受け取る`calculateMemberPrice`を実装してください。

- 最初に`let finalPrice = price;`と宣言する
- `isMember`が`true`なら、`finalPrice`を割引後の価格へ再代入する
- 最後に`finalPrice`をreturnする
- 小数の丸め処理は不要

```js
calculateMemberPrice(1000, 0.2, true);  // 800
calculateMemberPrice(1000, 0.2, false); // 1000
calculateMemberPrice(500, 0, true);     // 500
```

割引後の価格は次の計算で求められます。

```text
価格 × (1 - 割引率)
```
