# Unit 1 / Q004：表示名を返す

## 問題

名前`name`と、ゲストかどうかを表すboolean値`isGuest`を受け取る`getDisplayName`を実装してください。

- `isGuest`が`true`なら、名前に関係なく`"ゲスト"`を返す
- `isGuest`が`false`なら、渡された`name`をそのまま返す

```js
getDisplayName("Alice", false); // "Alice"
getDisplayName("Alice", true);  // "ゲスト"
getDisplayName("", false);      // ""
```
