# Unit 1 / Q002：在庫メッセージを返す

## 問題

在庫数`stock`を受け取り、次のルールで文字列を返す`getStockMessage`を実装してください。

- `stock`が`1`以上なら、`"在庫あり"`を返す
- `stock`が`0`なら、`"在庫なし"`を返す

```js
getStockMessage(5); // "在庫あり"
getStockMessage(1); // "在庫あり"
getStockMessage(0); // "在庫なし"
```

負数や数値以外の入力は、今回は考えなくて構いません。

## 実装前にコメントで書くこと

1. 入力される値
2. 戻す値
3. 条件と、それぞれで返す値
