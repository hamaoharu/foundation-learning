# Unit 3 / Q001：`||`と`??`の出力予測

教材を一度読んだ後は、見返さず、コードも実行せずに回答してください。

## 問題

次のA〜Jで表示される値を答え、短い理由を書いてください。

```js
console.log("A", 0 || 10);
console.log("B", 0 ?? 10);
console.log("C", "" || "未入力");
console.log("D", "" ?? "未入力");
console.log("E", false || true);
console.log("F", false ?? true);
console.log("G", null || "なし");
console.log("H", null ?? "なし");
console.log("I", undefined || "なし");
console.log("J", undefined ?? "なし");
```
