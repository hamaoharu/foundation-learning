# Unit 3 / Q003：プロフィール概要を作る

## 問題

ユーザーオブジェクト`user`を受け取り、次の形の新しいオブジェクトを返す`createProfileSummary`を実装してください。

```js
{
  name: 値,
  score: 値,
  bio: 値,
}
```

ルール：

- `user.profile`は存在しない場合や`null`の場合がある
- `name`が`null`または`undefined`なら`"ゲスト"`
- `score`が`null`または`undefined`なら`0`
- `bio`が`null`または`undefined`なら`"未設定"`
- `score`の`0`はそのまま残す
- `bio`の空文字`""`はそのまま残す
- optional chainingと`??`を使う
- 元の`user`を変更せず、新しいオブジェクトを返す

## 入出力例

```js
createProfileSummary({
  profile: {
    name: "Alice",
    score: 0,
    bio: "",
  },
});
// { name: "Alice", score: 0, bio: "" }

createProfileSummary({});
// { name: "ゲスト", score: 0, bio: "未設定" }

createProfileSummary({ profile: null });
// { name: "ゲスト", score: 0, bio: "未設定" }
```

## 累積復習

- 関数の引数とreturn
- 新しいオブジェクトの生成
- 元データを変更しない処理
- `0`・空文字のtruthy/falsy
