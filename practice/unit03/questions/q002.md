## 問題

次のA〜Hについて、表示される値または発生するエラーを答えてください。短い理由も書いてください。

```js
const userA = {
  profile: {
    name: "Alice",
    score: 0,
    bio: "",
  },
};

const userB = {};
const userC = {
  profile: null,
};

console.log("A", userA.profile?.name);
console.log("B", userB.profile?.name);
console.log("C", userC.profile?.name);
console.log("D", userB.profile?.name ?? "ゲスト");
console.log("E", userA.profile?.score || 100);
console.log("F", userA.profile?.score ?? 100);
console.log("G", userA.profile?.bio || "未設定");
console.log("H", userA.profile?.bio ?? "未設定");
```
