# Unit 17 / Q002：`await`で成功値を受け取る

## 問題

次のコードを実行せずに読み、問1〜問6へ答えてください。

```js
async function getNumber() {
  return 5;
}

async function doubleNumber() {
  const value = await getNumber();
  return value * 2;
}

const result = doubleNumber();

result.then((value) => {
  console.log(value);
});
```

## 問1

`getNumber()`は何を返しますか。「Promise」と「成功値」の両方を使って答えてください。

## 問2

`await getNumber()`によって、変数`value`へ入る値はいくつですか。

## 問3

`doubleNumber()`内の`return value * 2`は、通常の数値を呼び出し元へ直接返すのでしょうか。それとも、別の意味になりますか。

## 問4

`doubleNumber()`が返すPromiseの最終的な成功値はいくつですか。

## 問5

`result`へ直接入っているのは数値ですか、Promiseですか。

## 問6

`console.log(value)`には何が表示されますか。
