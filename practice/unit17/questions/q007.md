# Unit 17 / Q007：最終統合問題—商品一覧を逐次・並行取得する

## 問題

商品ID一覧を取得した後、各商品の詳細を並行取得し、販売中商品の概要を返す`loadCatalog(mode, logs)`を実装してください。

## 処理の依存関係

```text
商品ID一覧を取得
↓ IDが必要なので、ここは先にawait
[1, 2, 3]
↓
各商品の詳細取得を同時に開始
↓ Promise.allでまとめてawait
商品詳細配列
↓
販売中商品の抽出・名前変換・合計
```

## 用意された関数

### `fetchProductIds(mode)`

- 通常は`[1, 2, 3]`でfulfilled
- `mode === "ids-failure"`なら`Error("ids unavailable")`でrejected

### `fetchProduct(id, mode)`

通常は、IDに対応した商品でfulfilledになります。

```js
{ id: 1, name: " Keyboard ", price: 5000, available: true }
{ id: 2, name: "Mouse", price: 3000, available: false }
{ id: 3, name: " Monitor ", price: 20000, available: true }
```

`mode === "product-failure"`かつ`id === 2`なら、`Error("product 2 unavailable")`でrejectedになります。

## 成功時の結果

```js
const logs = [];
const promise = loadCatalog("success", logs);

// promiseの最終成功値
{
  count: 2,
  names: ["Keyboard", "Monitor"],
  total: 25000,
}

// 処理完了後
logs;
// ["ids-loaded", "products-loaded", "summarized", "end"]
```

## 失敗時の結果

ID取得失敗・商品取得失敗のどちらも`catch`で次の形へ変換します。

```js
{
  count: 0,
  names: [],
  total: 0,
  error: "エラーメッセージ",
}
```

ログ：

```js
["error", "end"]
```

## 実装の順序

1. `loadCatalog`をasync関数にする
2. `try`内で`await fetchProductIds(mode)`を実行する
3. `logs`へ`"ids-loaded"`を追加する
4. `ids.map()`で、各`fetchProduct(id, mode)`が返すPromiseの配列を作る
5. `await Promise.all(...)`で商品詳細配列を受け取る
6. `logs`へ`"products-loaded"`を追加する
7. `available`が`true`の商品だけを`filter()`する
8. 販売中商品の名前を`trim()`した配列を`map()`で作る
9. 販売中商品の価格合計を、初期値`0`の`reduce()`で求める
10. `"summarized"`を追加し、件数・名前・合計をreturnする
11. `catch`で`"error"`を追加し、代替オブジェクトをreturnする
12. `finally`で`"end"`を追加する

## ルール

- `fetchProductIds`と各`fetchProduct`の関係は逐次にする
- 各`fetchProduct`同士は`Promise.all()`で並行にする
- `map()`内では`await`せず、Promiseをreturnする
- `.then()`・`.catch()`・`.finally()`は使わない
- 用意された取得関数は変更しない
- 元の商品配列を変更しない
