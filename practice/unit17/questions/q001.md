# Unit 17 / Q001：async関数の戻り値を読む

## 問題

次のコードを実行せずに読み、問1〜問5へ答えてください。

```js
async function getNumber() {
  return 5;
}

const result = getNumber();

result.then((value) => {
  console.log(value);
});
```

## 問1

`getNumber()`の戻り値は、数値ですか、それともPromiseですか。

## 問2

関数内の`return 5`は、何を意味しますか。

## 問3

`result`へ直接入っているのは何ですか。

## 問4

`result`は最終的にどの状態になり、成功値はいくつですか。

## 問5

`console.log(value)`には何が表示されますか。
