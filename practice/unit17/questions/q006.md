# Unit 17 / Q006：`Promise.all()`で独立処理を並行実行する

## 問題

用意された`fetchUser()`と`fetchSettings(shouldSucceed)`を`Promise.all()`でまとめて待ち、ダッシュボード用データを返す`loadDashboard(shouldSucceed, logs)`を実装してください。

2つの取得処理は互いの結果を必要としないため、並行実行できます。

## 成功時

```js
const logs = [];
const promise = loadDashboard(true, logs);

// promiseの最終成功値
{
  userName: "Haru",
  theme: "dark",
}

// 処理完了後
logs;
// ["loaded", "end"]
```

## 失敗時

`fetchSettings(false)`は`new Error("settings unavailable")`でrejectedになります。

```js
const logs = [];
const promise = loadDashboard(false, logs);

// catchで回復した後の最終成功値
{
  userName: "Guest",
  theme: "light",
  error: "settings unavailable",
}

// 処理完了後
logs;
// ["error", "end"]
```

## 実装の仕様

- `loadDashboard`をasync関数にする
- `try`内で`Promise.all()`をawaitする
- `Promise.all()`へ`fetchUser()`と`fetchSettings(shouldSucceed)`を渡す
- 結果を`user`と`settings`へ分割代入する
- 成功時は`"loaded"`を追加し、指定されたオブジェクトをreturnする
- `catch`では`"error"`を追加し、代替オブジェクトをreturnする
- `finally`では`"end"`を追加する

## ルール

- 2つの関数を個別に順番にawaitしない
- `.then()`・`.catch()`・`.finally()`は使わない
- 用意された取得関数は変更しない
- `finally`からreturnしない
