# Unit 17 / Q004：Promise chainをasync/awaitへ書き換える

## 問題

用意された`getScore(shouldSucceed)`を使い、`formatScore(shouldSucceed, logs)`をasync/awaitで実装してください。

Unit 16では、同じ処理を次のようなPromise chainで実装しました。

```js
return getScore(shouldSucceed)
  .then((score) => {
    logs.push("success");
    return `Score: ${score}`;
  })
  .catch((error) => {
    logs.push(`error: ${error.message}`);
    return "Score: unavailable";
  })
  .finally(() => {
    logs.push("end");
  });
```

これを`async`・`await`・`try/catch/finally`で書き換えます。

## 成功時

```js
const logs = [];
const promise = formatScore(true, logs);

// promiseの最終成功値
"Score: 80"

// 処理完了後
logs;
// ["success", "end"]
```

## 失敗時

```js
const logs = [];
const promise = formatScore(false, logs);

// catchで回復した後の最終成功値
"Score: unavailable"

// 処理完了後
logs;
// ["error: score unavailable", "end"]
```

## ルール

- `formatScore`をasync関数にする
- `try`内で`await getScore(shouldSucceed)`を使う
- 成功時は`"success"`を追加し、表示文字列をreturnする
- `catch`ではエラーログを追加し、代替文字列をreturnする
- `finally`では`"end"`を追加する
- `.then()`・`.catch()`・`.finally()`は使わない
- `getScore`は変更しない
