# Unit 17 / Q005：逐次実行と並行実行を選ぶ

## 問題

次の3つの状況について、処理を「逐次実行」すべきか、「並行実行」できるかを判断してください。理由も書いてください。

## 状況A：ユーザー取得後に投稿を取得する

```js
const user = await fetchUser();
const posts = await fetchPosts(user.id);
```

`fetchPosts()`を呼ぶには、`fetchUser()`で得た`user.id`が必要です。

### 問1

逐次実行と並行実行のどちらが適切ですか。理由も書いてください。

## 状況B：ユーザーと設定を取得する

```js
const user = await fetchUser();
const settings = await fetchSettings();
```

`fetchUser()`と`fetchSettings()`は、互いの結果を必要としません。

### 問2

逐次実行と並行実行のどちらが適切ですか。理由も書いてください。

### 問3

状況Bを`Promise.all()`で並行実行するコードを書いてください。分割代入を使い、変数名は`user`と`settings`にしてください。

## 状況C：商品ID一覧を取得後、各商品の詳細を取得する

```js
const ids = await fetchProductIds();
```

商品詳細は次の関数で取得できます。

```js
fetchProduct(id);
```

各`fetchProduct(id)`は、別の商品取得結果を必要としません。

### 問4

`fetchProductIds()`と各`fetchProduct(id)`の関係は、逐次と並行のどちらですか。

### 問5

ID一覧を取得した後、すべての商品詳細を並行取得するコードを書いてください。`map()`と`Promise.all()`を使用します。

## 回答時のルール

- 実行は不要
- 「前の結果が次に必要か」を基準に理由を書く
- 資料を参照した場合は記録する
