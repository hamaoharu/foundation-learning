# Unit 14 / Q006：モジュールの依存関係を読む

## 問題

次の3つのモジュールがあります。コードを実行せず、importの向きと各ファイルの責務を読んでください。

### `order-utils.mjs`

```js
export function calculateTotal(orders) {
  return orders.reduce((total, order) => {
    return total + order.price;
  }, 0);
}
```

### `order-service.mjs`

```js
import { calculateTotal } from "./order-utils.mjs";

export function createOrderSummary(orders) {
  const total = calculateTotal(orders);
  return {
    count: orders.length,
    total,
  };
}
```

### `main.mjs`

```js
import { createOrderSummary } from "./order-service.mjs";

const orders = [
  { id: 1, price: 1000 },
  { id: 2, price: 2000 },
];

console.log(createOrderSummary(orders));
```

## 問1

`main.mjs`が直接依存（import）しているファイルはどれですか。

## 問2

`order-service.mjs`が直接依存しているファイルはどれですか。

## 問3

処理全体の依存方向を、次の形式で書いてください。

```text
○○ → ○○ → ○○
```

矢印は「左のファイルが右のファイルをimportする」という意味です。

## 問4

`order-utils.mjs`から`main.mjs`をimportすると、依存関係にどのような問題が起きますか。

## 問5
