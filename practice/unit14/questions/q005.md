# Unit 14 / Q005：処理の責務を3ファイルへ分ける

## 問題

注文データから、支払い済み注文の件数と合計金額を表示します。

次の3つの責務を別ファイルへ分けて実装してください。

1. `order-utils.mjs`：注文データの抽出・集計
2. `report-utils.mjs`：集計結果を表示用文字列へ変換
3. `main.mjs`：データを用意し、関数を順番に呼び出して表示

## 仕様

### `order-utils.mjs`

次の2つを名前付きexportしてください。

- `getPaidOrders(orders)`：`status`が`"paid"`の注文だけを新しい配列で返す
- `calculateTotal(orders)`：注文の`price`を合計して返す。空配列なら`0`

### `report-utils.mjs`

`createOrderReport(count, total)`をdefault exportしてください。

戻り値は次の形式です。

```text
支払い済み: 2件 / 合計: 3500円
```

### `main.mjs`

次の注文データを変更せずに利用してください。

```js
const orders = [
  { id: 1, status: "paid", price: 1200 },
  { id: 2, status: "pending", price: 800 },
  { id: 3, status: "paid", price: 2300 },
];
```

処理の順序：

1. 支払い済み注文を抽出する
2. 件数と合計金額を求める
3. 表示用文字列を作る
4. `console.log()`で表示する

## ルール

- `order-utils.mjs`では`console.log()`を使わない
- `report-utils.mjs`では注文配列を抽出・集計しない
- `main.mjs`へ`filter`や`reduce`の処理を直接書かない
- 元の`orders`を変更しない
- `getPaidOrders`と`calculateTotal`は名前付きimportする
- `createOrderReport`は任意の名前でdefault importする

node practice/unit14/answers/q005/main.mjs
