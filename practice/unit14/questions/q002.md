# Unit 14 / Q002：複数の関数をexportし、別名でimportする

## 問題

`price-utils.mjs`に次の2つの関数を実装し、どちらも名前付きexportしてください。

- `addTax(price)`：価格に10%の税を加えた数値を返す
- `formatYen(price)`：数値を`"○○円"`という文字列にして返す

次に`main.mjs`で両方を名前付きimportしてください。ただし、`formatYen`はimport時に`toYenLabel`という別名を付けて使用します。

## 期待結果

```js
addTax(1000);
// 1100

formatYen(1100);
// "1100円"
```

`main.mjs`の実行結果：

```text
1100円
```

## ルール

- 2つの関数を`price-utils.mjs`から名前付きexportする
- 1つのimport文で両方を読み込む
- `formatYen`は`as`を使い、`toYenLabel`という名前で使用する
- `main.mjs`へ計算処理や文字列化処理を直接書かない
- `price-utils.mjs`では`console.log()`を使わない

## 実行方法

```bash
node practice/unit14/answers/q002/main.mjs
```
