# Unit 14 / Q003：default exportと名前付きexportを使い分ける

## 問題

`product-utils.mjs`には、次の2つを定義します。

- `formatProduct(product)`：商品を表示用文字列へ変換する関数
- `taxRate`：税率を表す数値

`formatProduct`はdefault export、`taxRate`は名前付きexportしてください。

次に`main.mjs`で両方をimportし、商品の表示用文字列を出力してください。default exportは`createProductLabel`という名前で受け取ってください。

## 仕様

```js
const product = {
  name: "Keyboard",
  price: 5000,
};
```

`formatProduct(product)`は、税率を使って税込価格を求め、次の文字列を返します。

```text
Keyboard: 5500円
```

## ルール

- `formatProduct`はdefault exportする
- `taxRate`は名前付きexportする
- 1つのimport文で両方を読み込む
- default exportは`createProductLabel`という名前でimportする
- `main.mjs`へ価格計算や文字列化を直接書かない
- `product-utils.mjs`では`console.log()`を使わない

## 実行方法

```bash
node practice/unit14/answers/q003/main.mjs
```
