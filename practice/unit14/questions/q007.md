# Unit 14 / Q007：最終統合問題—タスク進捗処理を分割する

## 問題

タスク一覧から完了件数と完了率を求め、進捗レポートを表示します。

次の依存方向になるよう、4ファイルへ分割して実装してください。

```text
main.mjs → task-service.mjs → task-utils.mjs
                            → report-utils.mjs
```

## 各ファイルの責務

### `task-utils.mjs`

`getCompletedTasks(tasks)`を実装し、名前付きexportしてください。

- `completed`が`true`のタスクだけを新しい配列で返す
- 元の配列を変更しない

### `report-utils.mjs`

`createProgressReport(completedCount, totalCount)`を実装し、default exportしてください。

- 完了率は`completedCount / totalCount * 100`で求める
- `Math.round()`で整数へ丸める
- `totalCount`が`0`の場合、完了率を`0`とする
- 次の形式の文字列を返す

```text
完了: 2/3件 (67%)
```

### `task-service.mjs`

`createTaskSummary(tasks)`を実装し、名前付きexportしてください。

1. `getCompletedTasks`で完了タスクを抽出する
2. 完了件数と全件数を`createProgressReport`へ渡す
3. 表示用文字列を返す

必要な関数はそれぞれのモジュールからimportしてください。

### `main.mjs`

`task-service.mjs`の`createTaskSummary`だけをimportし、次のデータを渡して結果を表示してください。

```js
const tasks = [
  { id: 1, title: "HTML", completed: true },
  { id: 2, title: "CSS", completed: false },
  { id: 3, title: "JavaScript", completed: true },
];
```

## 期待する出力

```text
完了: 2/3件 (67%)
```

## ルール

- 図に示した依存方向を守る
- 循環importを作らない
- `main.mjs`からutils系ファイルを直接importしない
- `console.log()`は`main.mjs`だけで使う
- 各関数は指定された値を`return`する
- 元の`tasks`を変更しない

## 追加確認

実装後、空配列を渡した場合も次の結果になることを確認してください。

```js
createTaskSummary([]);
// "完了: 0/0件 (0%)"
```
