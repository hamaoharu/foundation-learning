# Unit 14 / Q004：モジュールスコープを読む

## 問題

次の3ファイルがあるものとして、コードを実行せずに問1〜問4へ答えてください。

### `user-module.mjs`

```js
const prefix = "User";

export function createLabel(name) {
  return `${prefix}: ${name}`;
}
```

### `product-module.mjs`

```js
const prefix = "Product";

export function createLabel(name) {
  return `${prefix}: ${name}`;
}
```

### `main.mjs`

```js
import { createLabel as createUserLabel } from "./user-module.mjs";
import { createLabel as createProductLabel } from "./product-module.mjs";

console.log(createUserLabel("Haru"));
console.log(createProductLabel("Keyboard"));
```

## 問1

1行目には何が表示されますか。

## 問2

2行目には何が表示されますか。

## 問3

2つのファイルで同じ`prefix`という変数名を使っても、衝突しないのはなぜですか。

## 問4

`main.mjs`から`prefix`を直接使えますか。使える／使えないの理由も書いてください。

## 回答時のルール

- 実行せずに答える
- 資料を参照した場合は記録する
- 「ファイルが違うから」だけでなく、exportとスコープに触れて説明する
