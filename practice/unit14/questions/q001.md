# Unit 14 / Q001：関数を別ファイルから読み込む

## 問題

`user-utils.mjs`に`formatUserName`関数を実装し、名前付きexportしてください。

次に`main.mjs`から名前付きimportし、用意されたユーザー名を整形して`formattedName`へ代入してください。

## 仕様

`formatUserName(name)`は：

1. 前後の空白を`trim()`で除く
2. `toLowerCase()`で小文字にする
3. 整形した文字列を返す

## 期待結果

```js
formatUserName("  HARU  ");
// "haru"

formatUserName(" Aki ");
// "aki"
```

`main.mjs`では：

```js
const rawName = "  HARU  ";
const formattedName = formatUserName(rawName);

console.log(formattedName);
// "haru"
```

## ルール

- `user-utils.mjs`から名前付きexportする
- `main.mjs`で名前付きimportする
- importパスには`./user-utils.mjs`を使う
- `user-utils.mjs`では`console.log()`を使わない
- 整形処理を`main.mjs`へ直接書かない

## 実行方法

回答フォルダへ移動せず、プロジェクトルートから次を実行できます。

```bash
node practice/unit14/answers/q001/main.mjs
```
