## 必須の修正

アロー関数で波括弧を使う場合、戻り値は自動では返らない。

```js
(name) => {
  name.trim().toLowerCase();
}
```

このコールバックの戻り値は`undefined`になるため、`map`は要素数分の`undefined`を集めた配列を返す。

波括弧を使う場合は`return`を明示する。

または、処理が1つなら波括弧を外すと、その式の値が暗黙的に返る。

## 実行結果

```text
["  Keyboard ", "MOUSE", " Monitor  "]
→ [undefined, undefined, undefined]
```

`JSON.stringify`では、配列内の`undefined`が`null`として表示されることがある。
