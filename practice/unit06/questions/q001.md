# Unit 6 / Q001：商品名を表示用に変換する

## 問題

商品名の文字列配列`names`を受け取り、各要素の前後の空白を削除して小文字に変換した、新しい配列を返す`normalizeProductNames`を実装してください。

## ルール

- `map`を使う
- `for`、`for...of`、`forEach`は使わない
- 元の配列を変更しない
- 要素数を減らさない

## 入出力例

```js
normalizeProductNames(["  Keyboard ", "MOUSE", " Monitor  "]);
// ["keyboard", "mouse", "monitor"]

normalizeProductNames(["  A  ", ""]);
// ["a", ""]

normalizeProductNames([]);
// []
```

## 累積復習

- 関数と`return`
- `trim()`
- `toLowerCase()`
- 元配列を変更しない処理
