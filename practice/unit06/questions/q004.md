# Unit 6 / Q004：合格点だけを残す

## 問題

点数の配列`scores`を受け取り、60点以上の点数だけを残した新しい配列を返す`collectPassingScores`を実装してください。

## ルール

- `filter`を使う
- `map`、`for`、`for...of`、`forEach`は使わない
- 点数の値は変換しない
- 元配列を変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
collectPassingScores([80, 59, 60, 100, 40]);
// [80, 60, 100]

collectPassingScores([59, 0]);
// []

collectPassingScores([]);
// []
```

## 考えるポイント

コールバックが返すのは点数そのものではなく、「その点数を残すかどうか」を表す値です。

## 累積復習

- 比較演算子
- コールバックの`return`
- 境界値の60
- 元配列を変更しない処理
