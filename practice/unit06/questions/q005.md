# Unit 6 / Q005：購入可能な商品だけを残す

## 問題

商品オブジェクトの配列`products`を受け取り、次の条件を両方満たす商品だけを残した新しい配列を返す`collectAvailableProducts`を実装してください。

- `stock`が1以上
- `isPublished`が`true`

## ルール

- `filter`を使う
- `map`、`for`、`for...of`、`forEach`は使わない
- 商品オブジェクトの形や値を変更しない
- 元の配列と商品オブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
const products = [
  { id: 1, name: "Keyboard", stock: 3, isPublished: true },
  { id: 2, name: "Mouse", stock: 0, isPublished: true },
  { id: 3, name: "Monitor", stock: 5, isPublished: false },
  { id: 4, name: "Cable", stock: 1, isPublished: true },
];

collectAvailableProducts(products);
// [
//   { id: 1, name: "Keyboard", stock: 3, isPublished: true },
//   { id: 4, name: "Cable", stock: 1, isPublished: true },
// ]

collectAvailableProducts([]);
// []
```

## 考えるポイント

- 2つの条件を同時に満たす場合に使う論理演算子は何か
- `filter`は新しいオブジェクトを作るのではなく、条件に合う元の要素を残す

## 累積復習

- `filter`のコールバックと`return`
- 比較演算子
- 論理演算子
- オブジェクトのプロパティ参照
- 境界値の`stock: 1`
