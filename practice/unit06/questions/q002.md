# Unit 6 / Q002：ユーザーを表示用オブジェクトへ変換する

## 問題

ユーザーオブジェクトの配列`users`を受け取り、各ユーザーを次の形へ変換した新しい配列を返す`createUserLabels`を実装してください。

```js
{
  id: 元のid,
  label: 前後の空白を削除して大文字にしたname,
}
```

## ルール

- `map`を使う
- `for`、`for...of`、`forEach`は使わない
- 新しいオブジェクトを返す
- 元の配列とユーザーオブジェクトを変更しない
- 今回はコールバック内で波括弧と`return`を明示する

## 入出力例

```js
const users = [
  { id: 1, name: "  Haru " },
  { id: 2, name: "sora" },
];

createUserLabels(users);
// [
//   { id: 1, label: "HARU" },
//   { id: 2, label: "SORA" },
// ]

createUserLabels([]);
// []
```

## 累積復習

- `map`のコールバックと`return`
- オブジェクトのプロパティ参照
- 新しいプレーンオブジェクトの生成
- `trim()`と`toUpperCase()`
- 非破壊処理
