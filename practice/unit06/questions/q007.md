# Unit 6 / Q007：有効なユーザー名を表示用に加工する

## 問題

ユーザーオブジェクトの配列`users`を受け取り、次の処理を順番に行った新しい配列を返す`createActiveUserNames`を実装してください。

1. `isActive`が`true`のユーザーだけを残す
2. 残った各ユーザーの`name`を、前後の空白を削除して大文字に変換する

結果は文字列の配列です。

## ルール

- `filter`と`map`を両方使う
- `filter(...).map(...)`の順番でつなげる
- `for`、`for...of`、`forEach`は使わない
- 元の配列とユーザーオブジェクトを変更しない
- 両方のコールバックで波括弧と`return`を明示する

## 入出力例

```js
const users = [
  { id: 1, name: "  Haru ", isActive: true },
  { id: 2, name: "Sora", isActive: false },
  { id: 3, name: " ren ", isActive: true },
];

createActiveUserNames(users);
// ["HARU", "REN"]

createActiveUserNames([]);
// []
```

## 考えるポイント

- `filter`はどのユーザーを残すか決める
- `map`は残ったユーザーを何へ変換するか決める
- `filter`が返した配列に対して、続けて`map`を呼び出せる

## 累積復習

- Booleanプロパティの条件判定
- `trim()`と`toUpperCase()`
- メソッドチェーン
- 元データを変更しない処理
