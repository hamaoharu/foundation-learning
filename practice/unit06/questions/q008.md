# Unit 6 / Q008：初見確認—販売中の商品を表示データへ変換する

## 問題

商品オブジェクトの配列`products`を受け取り、次の処理を順番に行った新しい配列を返す`createSaleItems`を実装してください。

1. `price`が1000以上、かつ`stock`が1以上の商品だけを残す
2. 残った各商品を次の新しいオブジェクトへ変換する

```js
{
  id: 元のid,
  label: 前後の空白を削除したnameとpriceを「商品名：価格円」の形式でつないだ文字列,
}
```

## ルール

- `filter`と`map`を両方使う
- `filter(...).map(...)`の順番でつなげる
- `for`、`for...of`、`forEach`は使わない
- 両方のコールバックで波括弧と`return`を明示する
- 元の配列と商品オブジェクトを変更しない
- まず資料と過去の回答を見ずに実装する

## 入出力例

```js
const products = [
  { id: 1, name: " Keyboard ", price: 5000, stock: 2 },
  { id: 2, name: "Mouse", price: 900, stock: 4 },
  { id: 3, name: " Monitor  ", price: 20000, stock: 0 },
  { id: 4, name: "Cable", price: 1000, stock: 1 },
];

createSaleItems(products);
// [
//   { id: 1, label: "Keyboard：5000円" },
//   { id: 4, label: "Cable：1000円" },
// ]

createSaleItems([]);
// []
```

## 完了判定

- `filter`の戻り値と`map`の戻り値を使い分けられる
- 1000円と在庫1の境界値を含められる
- 新しいオブジェクトを返せる
- 元データを変更しない
