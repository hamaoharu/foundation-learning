# Unit 6 / Q003：順番付きのタスク名へ変換する

## 問題

タスク名の文字列配列`tasks`を受け取り、前後の空白を削除したうえで、先頭に1から始まる順番を付けた新しい配列を返す`createNumberedTasks`を実装してください。

## ルール

- `map`を使う
- コールバックの2番目の引数で添字を受け取る
- `for`、`for...of`、`forEach`は使わない
- 元配列を変更しない
- 要素数を減らさない

## 入出力例

```js
createNumberedTasks(["  設計", "実装  ", "  テスト  "]);
// ["1. 設計", "2. 実装", "3. テスト"]

createNumberedTasks(["確認"]);
// ["1. 確認"]

createNumberedTasks([]);
// []
```

## 累積復習

- `map`のコールバックと戻り値
- 配列の添字
- `trim()`
- テンプレートリテラル
