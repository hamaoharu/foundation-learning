# Unit 6 / Q006：有効な名前だけを残す

## 問題

名前の文字列配列`names`を受け取り、前後の空白を無視した文字数が3文字以上の名前だけを残した新しい配列を返す`collectValidNames`を実装してください。

ただし、今回は名前そのものを整形せず、**元の文字列のまま**結果へ残してください。

## ルール

- `filter`を使う
- `map`、`for`、`for...of`、`forEach`は使わない
- 条件の判定時だけ`trim()`を使う
- 結果には元の文字列をそのまま残す
- 元配列を変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
collectValidNames(["  Haru ", "Ai", " Sora", "", " Ren "]);
// ["  Haru ", " Sora", " Ren "]

collectValidNames([" A ", "Yu", "   "]);
// []

collectValidNames([]);
// []
```

## 考えるポイント

`trim()`した文字列は条件判定に使いますが、`filter`が結果へ残すのはコールバックの戻り値ではなく、元配列の要素です。

## 累積復習

- `filter`のコールバックと`return`
- `trim()`と`length`
- 元の値を変更しない処理
