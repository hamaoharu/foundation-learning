# Unit 12 / Q002：関数が参照する変数を読む

## 問題

次のコードを**実行せずに**読み、問1〜問3へ回答してください。

```js
const message = "global";

function readMessage() {
  return message; // ①
}

function run() {
  const message = "local";
  return readMessage(); // ②
}

console.log(run()); // ③
```

## 問1

③には`"global"`と`"local"`のどちらが表示されますか。

## 問2

①の`message`は、次のどちらを参照しますか。

- コードの最上位にある`message`
- `run`関数内にある`message`

## 問3

その参照先になる理由を、「定義した場所」と「呼び出した場所」という言葉を使って説明してください。

## 考えるポイント

- `readMessage`を定義した場所から見える変数を確認する
- `readMessage`を呼び出している②の周囲にある変数へ、呼び出し時だけ切り替わるわけではない
- 関数が参照できる外側の範囲は、基本的に定義位置によって決まる
