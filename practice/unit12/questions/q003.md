# Unit 12 / Q003：定義がネストした関数を読む

## 問題

次のコードを**実行せずに**読み、問1・問2へ回答してください。

```js
const message = "global";

function run() {
  const message = "local";

  function readMessage() { // ① 定義
    return message;         // ②
  }

  return readMessage();     // ③ 呼び出し
}

console.log(run());         // ④
```

## 問1

④には`"global"`と`"local"`のどちらが表示されますか。

## 問2

Q002では`readMessage`を最上位で定義していました。今回は何が違うため、②の`message`の参照先が決まりますか。

「関数の定義」と「runの内側」という言葉を使って説明してください。

## 比較

```js
// Q002：定義は最上位
function readMessage() {}

function run() {
  readMessage(); // 呼び出しだけが内側
}
```

```js
// Q003：定義そのものがrunの内側
function run() {
  function readMessage() {}
  readMessage();
}
```
