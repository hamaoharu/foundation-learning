# Unit 12 / Q008：条件関数で要素を選ぶ

## 問題

配列`values`と条件関数`predicate`を受け取り、`predicate`が`true`を返した要素だけを集めた新しい配列を返す`selectValues`を実装してください。

JavaScript標準の`filter()`に近い処理を、今回は`for...of`で作ります。

## 入出力例

```js
function isEven(number) {
  return number % 2 === 0;
}

selectValues([1, 2, 3, 4], isEven);
// [2, 4]

selectValues(["JS", "CSS", "HTML"], (value) => {
  return value.length >= 3;
});
// ["CSS", "HTML"]

selectValues([], isEven);
// []
```

## ルール

- 結果用の空配列を作る
- `for...of`で`values`を繰り返す
- 各要素を`predicate`へ渡して実行する
- `predicate(value)`が`true`の場合だけ、元の`value`を結果配列へ`push()`する
- 標準の`filter()`は使わない
- 元の配列を変更しない

## Q007との違い

```text
Q007 transformValues
→ コールバックが返した変換後の値をpush

Q008 selectValues
→ コールバックが返した真偽値を判定し、元の値をpush
```

`predicate`が返した`true`自体を配列へ入れるわけではありません。
