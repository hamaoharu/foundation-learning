# Unit 12 / Q007：コールバックで配列を変換する

## 問題

配列`values`と変換関数`transform`を受け取り、各要素を`transform`へ渡した結果を集めた新しい配列を返す`transformValues`を実装してください。

JavaScript標準の`map()`に近い処理を、今回は`for...of`で作ります。

## 入出力例

```js
function double(number) {
  return number * 2;
}

transformValues([1, 2, 3], double);
// [2, 4, 6]

transformValues([1, 2, 3], (number) => `No.${number}`);
// ["No.1", "No.2", "No.3"]

transformValues([], double);
// []
```

## ルール

- 結果用の空配列を作る
- `for...of`で`values`を繰り返す
- 各要素を`transform`へ渡して実行する
- `transform`の戻り値を`push()`で結果配列へ追加する
- 最後に結果配列を返す
- 標準の`map()`は使わない
- 元の`values`を変更しない

## 処理の形

```text
valuesの要素を1つ取り出す
  ↓
transform(要素)を実行
  ↓
戻り値を結果配列へpush
  ↓
次の要素へ
```
