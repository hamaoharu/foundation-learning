# Unit 12 / Q001：変数が見える範囲を読む

## 問題

次のコードを**実行せずに**読み、問1〜問4へ回答してください。

```js
const label = "global";

function showLabel() {
  const label = "function";

  if (true) {
    const blockMessage = "block";
    console.log(label);
    console.log(blockMessage);
  }

  console.log(label);
  console.log(blockMessage);
}

showLabel();
console.log(label);
```

## 問1

最初の`console.log(label)`には何が表示されますか。

## 問2

`if`ブロック内の`console.log(blockMessage)`には何が表示されますか。

## 問3

`if`ブロックの後にある`console.log(label)`には何が表示されますか。

## 問4

次の行では、値が表示されますか、それともエラーになりますか。理由も書いてください。

```js
console.log(blockMessage);
```

この行でエラーが発生するため、実際の実行ではその後の`console.log(label)`まで到達しません。ただし、最後の`label`がどのスコープの値かもあわせて考えてください。
