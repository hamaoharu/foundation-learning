# Unit 12 / Q009：範囲を判定する関数を作る

## 問題

最小値`min`と最大値`max`を受け取り、「数値がその範囲内か判定する関数」を返す`createRangeChecker`を実装してください。

範囲には`min`と`max`自身も含みます。

## 入出力例

```js
const isAdultWorkingAge = createRangeChecker(18, 65);

isAdultWorkingAge(17);
// false

isAdultWorkingAge(18);
// true

isAdultWorkingAge(40);
// true

isAdultWorkingAge(65);
// true

isAdultWorkingAge(66);
// false
```

返された関数は、`filter()`のコールバックとしても使える必要があります。

```js
const isScoreInRange = createRangeChecker(60, 80);

[50, 60, 70, 80, 90].filter(isScoreInRange);
// [60, 70, 80]
```

別々に作った判定関数は、別々の範囲を使います。

```js
const isSingleDigit = createRangeChecker(0, 9);
const isTeen = createRangeChecker(13, 19);

isSingleDigit(5); // true
isTeen(5);        // false
```

## ルール

- `createRangeChecker`から関数を返す
- 返す関数は数値`value`を1つ受け取る
- 外側の`min`と`max`を使って判定する
- `min <= value`かつ`value <= max`のときだけ`true`を返す
- グローバル変数は使わない

## この問題で組み合わせる内容

```text
クロージャ
→ 返された関数がminとmaxを利用し続ける

コールバック
→ 返された関数をfilterへ渡せる

高階関数
→ createRangeCheckerは関数を返す
→ filterは関数を受け取る
```
