# Unit 12 / Q006：受け取った関数を実行する

## 問題

値`value`と関数`operation`を受け取り、`value`を`operation`へ渡して実行した結果を返す`applyOperation`を実装してください。

## 入出力例

```js
function double(number) {
  return number * 2;
}

function toLabel(number) {
  return `結果: ${number}`;
}

applyOperation(5, double);
// 10

applyOperation(5, toLabel);
// "結果: 5"

applyOperation(4, (number) => number + 1);
// 5
```

## ルール

- `operation`を関数として呼び出す
- 呼び出すときに`value`を引数として渡す
- `operation`の戻り値を`applyOperation`から返す
- `operation`の種類ごとの`if`文は書かない

## 考えるポイント

```js
applyOperation(5, double);
```

この呼び出しでは：

```text
value     → 5
operation → double関数そのもの
```

`double`と`double()`の違いに注意してください。

```js
applyOperation(5, double);   // 関数を渡す
applyOperation(5, double()); // 先に関数を実行してしまう
```

## 累積復習

- 関数の引数と戻り値
- 関数も値として渡せること
- コールバック関数
