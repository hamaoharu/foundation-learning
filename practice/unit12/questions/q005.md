# Unit 12 / Q005：指定した数を足す関数を作る

## 問題

数値`amount`を受け取り、「渡された数値へ`amount`を加える関数」を返す`createAdder`を実装してください。

## 入出力例

```js
const add10 = createAdder(10);
const add3 = createAdder(3);

add10(5);
// 15

add10(20);
// 30

add3(5);
// 8
```

## ルール

- `createAdder`から関数を返す
- 返す関数は、引数として`number`を1つ受け取る
- 返す関数から`number + amount`を返す
- グローバル変数は使わない

## 骨組み

```js
function createAdder(amount) {
  return function add(number) {
    // numberと外側のamountを使う
  };
}
```

## 考えるポイント

```js
const add10 = createAdder(10);
```

この時点で`add10`には、`amount = 10`を利用できる`add`関数が入ります。

```js
add10(5);
```

では、内側の引数`number`が`5`、外側から保持している`amount`が`10`です。
