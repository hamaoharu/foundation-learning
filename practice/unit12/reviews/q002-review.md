# Unit 12 / Q002 レビュー

## 判定

解説後合格。

## 確認できたこと

- `readMessage()`の戻り値が、そのまま`run()`の戻り値になると理解できた
- `readMessage`は最上位で定義されているため、最上位の`message`を参照すると判断できた
- `run`内の`message`は`readMessage`の外側のスコープではないと判断できた
- 関数を呼び出す位置と、関数を定義する位置を区別できた

## 混乱した点

`run`内に`readMessage()`という呼び出しがあるため、`readMessage`の定義自体も`run`内にネストしているように捉えていた。

```text
readMessage()がrun内にある
→ 呼び出しが内側にあるだけ

function readMessage() {}がrun内にある
→ 定義が内側にある
```

レキシカルスコープは後者の定義位置によって決まる。次の類題で、実際に定義がネストしている場合と比較する。
