## 正しくできている点

- `for...of`で配列を1回だけ処理している
- `total`を正しく加算できている
- `number > 0`で正数だけを数えられている
- 新しいオブジェクトを返し、元の配列を変更していない

## 必須の修正

### 1. `number`を宣言する

`for (number of numbers)`ではなく、ループ内だけで使う変数として宣言する。

宣言しないコードは、実行環境によってグローバル変数を作ったり、`ReferenceError`になったりする。

### 2. `max`の初期状態を扱う

現在の`max`は最初が`undefined`。

```js
undefined < 10
```

比較時に`undefined`が`NaN`へ変換され、結果は`false`になる。そのため、`max`は一度も更新されない。

- 空配列の結果は`null`にする
- 最初の要素では、大小比較をせず最大値として採用する
- 2個目以降は、現在の最大値より大きい場合に更新する

という処理が必要。

## 実行結果

```text
[10, -5, 20, 0] → { total: 25, max: undefined, positiveCount: 2 }
[-10, -3]        → { total: -13, max: undefined, positiveCount: 0 }
[]               → { total: 0, max: undefined, positiveCount: 0 }
```

## 次の完了条件

- 通常の配列で最大値が求められる
- 全要素が負数でも最大値が求められる
- 空配列では`max: null`になる
- ループ変数が宣言されている

すべて達成した。
