# Unit 5 / Q002：表示可能な名前を抽出する

## 問題

文字列の配列`names`を受け取り、前後の空白を削除した文字数が3文字以上の名前だけを、新しい配列として返す`collectDisplayNames`を実装してください。

返す配列には、前後の空白を削除した名前を格納してください。

## ルール

- `for...of`を使う
- `push`を使う
- `filter`、`map`は使わない
- 元の配列を変更しない
- 空配列なら空配列を返す

## 入出力例

```js
collectDisplayNames(["  Haru ", "Ai", " Sora", "", " Ren "]);
// ["Haru", "Sora", "Ren"]

collectDisplayNames([" A ", "Yu"]);
// []

collectDisplayNames([]);
// []
```

## 累積復習

- 関数と`return`
- 条件分岐
- 文字列の`trim()`と`length`
- 新しい配列を作る考え方
