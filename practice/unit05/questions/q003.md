# Unit 5 / Q003：IDが一致する商品を探す

## 問題

商品オブジェクトの配列`products`と数値`targetId`を受け取り、`id`が一致する商品の表示用文字列を返す`findProductLabel`を実装してください。

一致する商品がない場合は、`"商品が見つかりません"`を返してください。

## ルール

- `for...of`を使う
- IDの比較には`===`を使う
- 一致した時点で`return`する
- `find`、`filter`、`map`は使わない
- 元の配列と商品オブジェクトを変更しない

## 表示形式

```text
商品名（価格円）
```

## 入出力例

```js
const products = [
  { id: 1, name: "Keyboard", price: 5000 },
  { id: 2, name: "Mouse", price: 3000 },
];

findProductLabel(products, 2);
// "Mouse（3000円）"

findProductLabel(products, 9);
// "商品が見つかりません"

findProductLabel([], 1);
// "商品が見つかりません"
```

## 累積復習

- 関数と`return`
- `for...of`
- 厳密等価演算子`===`
- オブジェクトのプロパティ参照
- テンプレートリテラル
