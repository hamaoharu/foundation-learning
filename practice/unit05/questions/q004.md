# Unit 5 / Q004：元配列を守って末尾を取り出す

## 問題

配列`items`を受け取り、元の配列を変更せずに末尾の要素を取り出す`takeLastSafely`を実装してください。

次の形の新しいオブジェクトを返します。

```js
{
  taken: 取り出した末尾の要素,
  remaining: 末尾を除いた新しい配列,
}
```

空配列の場合、`taken`は`null`、`remaining`は空の新しい配列にしてください。

## ルール

- `slice()`を使って配列をコピーする
- コピーした配列に`pop()`を使う
- 元の配列を変更しない
- `items`と`remaining`は別の配列でなければならない

## 入出力例

```js
const original = ["A", "B", "C"];
const result = takeLastSafely(original);

result;
// { taken: "C", remaining: ["A", "B"] }

original;
// ["A", "B", "C"]

takeLastSafely([]);
// { taken: null, remaining: [] }
```

## 累積復習

- `const`と`let`
- 配列の`length`
- `null`
- 条件分岐
- 新しいプレーンオブジェクトの生成
- `return`
