# Unit 5 / Q001：数値配列を集計する

## 問題

数値配列`numbers`を受け取り、次の形の新しいプレーンオブジェクトを返す`summarizeNumbers`を実装してください。

```js
{
  total: 合計,
  max: 最大値,
  positiveCount: 0より大きい数の個数,
}
```

## ルール

- `for...of`を使う
- 配列を1回だけループする
- `reduce`、`filter`、`Math.max`は使わない
- 空配列の場合は`{ total: 0, max: null, positiveCount: 0 }`
- 元の配列を変更しない

## 入出力例

```js
summarizeNumbers([10, -5, 20, 0]);
// { total: 25, max: 20, positiveCount: 2 }

summarizeNumbers([-10, -3]);
// { total: -13, max: -3, positiveCount: 0 }

summarizeNumbers([]);
// { total: 0, max: null, positiveCount: 0 }
```

## 累積復習

- 関数とreturn
- `let`による累積
- 条件分岐
- `===`
- 新しいプレーンオブジェクトの生成
