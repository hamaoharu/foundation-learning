# Unit 5 / Q005：初見確認—気温データを集計する

## 問題

気温の配列`temperatures`を受け取り、次の形の新しいオブジェクトを返す`analyzeTemperatures`を実装してください。

```js
{
  total: 気温の合計,
  min: 最小値,
  freezingCount: 0以下の値の個数,
}
```

## ルール

- `for...of`を使う
- 配列を1回だけループする
- `reduce`、`filter`、`Math.min`は使わない
- 空配列では`{ total: 0, min: null, freezingCount: 0 }`を返す
- 元の配列を変更しない
- まず資料を見ずに実装する

## 入出力例

```js
analyzeTemperatures([5, -2, 0, 8, -7]);
// { total: 4, min: -7, freezingCount: 3 }

analyzeTemperatures([10, 3]);
// { total: 13, min: 3, freezingCount: 0 }

analyzeTemperatures([]);
// { total: 0, min: null, freezingCount: 0 }
```
