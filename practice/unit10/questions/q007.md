# Unit 10 / Q007：対象ユーザーのスキルを非破壊で追加する

## 問題

ユーザー配列`users`、対象ID`targetId`、追加するスキル`newSkill`を受け取り、対象ユーザーの`profile.skills`の末尾にスキルを追加した**新しい配列**を返す`addUserSkill`を実装してください。

## ルール

- `map()`とスプレッド構文を使う
- 元の配列、ユーザー、`profile`、`skills`を変更しない
- 対象ユーザーについて、次のすべてを新しい参照にする
  - ユーザーオブジェクト
  - `profile`オブジェクト
  - `skills`配列
- 対象外のユーザーは同じ参照を再利用する
- 対象が存在しない場合もエラーを出さない
- `push()`は使わない

## 入出力例

```js
const users = [
  {
    id: 1,
    name: "Haru",
    profile: {
      city: "Tokyo",
      skills: ["HTML"],
    },
  },
  {
    id: 2,
    name: "Aki",
    profile: {
      city: "Osaka",
      skills: ["CSS"],
    },
  },
];

const updated = addUserSkill(users, 2, "JavaScript");

console.log(updated[1].profile.skills);
// ["CSS", "JavaScript"]

console.log(users[1].profile.skills);
// ["CSS"]

console.log(updated === users);
// false

console.log(updated[0] === users[0]);
// true

console.log(updated[1] === users[1]);
// false

console.log(updated[1].profile === users[1].profile);
// false

console.log(updated[1].profile.skills === users[1].profile.skills);
// false
```

## 考え方を分解する

対象ユーザーでは、変更する値までの経路をすべて新しくします。

```text
users配列
  └─ 対象user
       └─ profile
            └─ skillsへnewSkillを追加
```

1. `map()`で新しい外側の配列を作る
2. 対象外なら元の`user`を返す
3. 対象なら新しい`user`を返す
4. その中で新しい`profile`を作る
5. その中で新しい`skills`配列を作る
