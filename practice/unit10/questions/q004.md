# Unit 10 / Q004：浅いコピーの参照を読む

## 問題

次のコードは、オブジェクトをスプレッド構文でコピーしてから、コピー側の値を変更しています。

**コードを実行せずに**、問1〜問5へ回答してください。

```js
const original = {
  name: "Haru",
  profile: {
    city: "Tokyo",
  },
};

const copied = { ...original };

copied.name = "Aki";
copied.profile.city = "Osaka";

console.log(original.name);
console.log(original.profile.city);
console.log(original === copied);
console.log(original.profile === copied.profile);
```

## 問1

`console.log(original.name)`には何が表示されますか。

## 問2

`console.log(original.profile.city)`には何が表示されますか。

## 問3

`console.log(original === copied)`には何が表示されますか。

## 問4

`console.log(original.profile === copied.profile)`には何が表示されますか。

## 問5

問1と問2で結果が異なる理由を、次の言葉を使って説明してください。

- 浅いコピー
- 外側
- `profile`
- 参照
