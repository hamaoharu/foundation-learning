# Unit 10 / Q003：配列へ要素を非破壊で追加する

## 問題

文字列の配列`skills`と、新しく追加する文字列`newSkill`を受け取り、末尾に`newSkill`を追加した**新しい配列**を返す`addSkill`を実装してください。

## ルール

- 配列のスプレッド構文を使う
- 元の`skills`を変更しない
- `push()`は使わない
- 戻り値は`skills`とは別の配列にする
- 元の要素の順序を維持し、`newSkill`を末尾に追加する

## 入出力例

```js
const skills = ["HTML", "CSS"];
const added = addSkill(skills, "JavaScript");

console.log(added);
// ["HTML", "CSS", "JavaScript"]

console.log(skills);
// ["HTML", "CSS"]

console.log(added === skills);
// false
```

空配列でも動作する必要があります。

```js
addSkill([], "JavaScript");
// ["JavaScript"]
```

## 考えるポイント

- オブジェクトでは`{ ...user }`と書いた
- 配列では新しい`[]`の中へ、元の要素を`...`で展開する
- 新しい要素をスプレッドの後ろに置くと、末尾へ追加できる

## 累積復習

- 配列とオブジェクトの違い
- 関数の戻り値
- `push()`が元の配列を変更すること
- 元データを変更しない処理
