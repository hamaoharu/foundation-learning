# Unit 10 / Q005：配列内の対象オブジェクトを更新する

## 問題

Todoオブジェクトの配列`todos`と対象のID`targetId`を受け取り、対象Todoの`completed`だけを`true`にした**新しい配列**を返す`completeTodo`を実装してください。

## ルール

- `map()`を使う
- 対象Todoの更新にはオブジェクトのスプレッド構文を使う
- 元の配列と、元のTodoオブジェクトを変更しない
- `id`が`targetId`と一致するTodoだけを更新する
- 一致しないTodoはそのまま返す
- 対象が存在しない場合も、エラーを出さずに同じ内容の新しい配列を返す

## 入出力例

```js
const todos = [
  { id: 1, title: "HTMLを復習する", completed: false },
  { id: 2, title: "JavaScriptを書く", completed: false },
];

const updated = completeTodo(todos, 2);

console.log(updated);
// [
//   { id: 1, title: "HTMLを復習する", completed: false },
//   { id: 2, title: "JavaScriptを書く", completed: true },
// ]

console.log(todos[1].completed);
// false

console.log(updated === todos);
// false

console.log(updated[1] === todos[1]);
// false
```

## 考えるポイント

`map()`のコールバックでは、各Todoについて次を判断します。

```text
idがtargetIdと一致する
  → Todoをコピーし、completedをtrueで上書きして返す

一致しない
  → 元のTodoをそのまま返す
```

## 累積復習

- `map()`がコールバックの戻り値を集めて新しい配列を作ること
- 条件分岐
- オブジェクトのスプレッド構文
- 元データを変更しない更新
