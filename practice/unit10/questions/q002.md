# Unit 10 / Q002：ネストした住所を非破壊で更新する

## 問題

ユーザーオブジェクト`user`と新しい都市名`newCity`を受け取り、`profile.city`だけを変更した**新しいユーザーオブジェクト**を返す`updateUserCity`を実装してください。

## ルール

- スプレッド構文を使う
- 元の`user`と`user.profile`を変更しない
- 戻り値は`user`とは別のオブジェクトにする
- 戻り値の`profile`も`user.profile`とは別のオブジェクトにする
- `name`や`profile.age`など、`city`以外のプロパティを維持する

## 入出力例

```js
const user = {
  id: 1,
  name: "Haru",
  profile: {
    city: "Tokyo",
    age: 20,
  },
};

const moved = updateUserCity(user, "Osaka");

console.log(moved);
// {
//   id: 1,
//   name: "Haru",
//   profile: {
//     city: "Osaka",
//     age: 20,
//   },
// }

console.log(user.profile.city);
// "Tokyo"

console.log(moved === user);
// false

console.log(moved.profile === user.profile);
// false
```

## 考えるポイント

- Q001と同じ方法で、まず外側の`user`をコピーする
- `profile`を後ろに書いて、新しいオブジェクトで上書きする
- 新しい`profile`の中でも、元の`user.profile`をコピーする
- 最後に`city`だけを上書きする

## 累積復習

- スプレッド構文
- 同じプロパティを後ろの値で上書きする処理
- ネストしたオブジェクト
- 元データを変更しない処理
