# Unit 10 / Q001：ユーザー名を非破壊で更新する

## 問題

ユーザーオブジェクト`user`と新しい名前`newName`を受け取り、名前だけを変更した**新しいオブジェクト**を返す`renameUser`を実装してください。

## ルール

- スプレッド構文を使う
- 元の`user`を変更しない
- 戻り値は`user`とは別のオブジェクトにする
- `id`や`role`など、`name`以外のプロパティも維持する

## 入出力例

```js
const user = {
  id: 1,
  name: "Haru",
  role: "member",
};

const renamed = renameUser(user, "Aki");

console.log(renamed);
// { id: 1, name: "Aki", role: "member" }

console.log(user);
// { id: 1, name: "Haru", role: "member" }

console.log(renamed === user);
// false
```

## 考えるポイント

- 最初に`user`の全プロパティを新しいオブジェクトへ展開する
- 同じ`name`を後ろに書くと、展開された古い名前を上書きできる
- `user.name = newName`は元データを変更するため、今回は使わない

## 累積復習

- オブジェクトの生成
- プロパティの上書き
- 関数の引数と戻り値
- 元データを変更しない処理
