# Unit 10 / Q006：ネストしたデータを深くコピーする

## 問題

設定オブジェクト`settings`を受け取り、ネストした配列やオブジェクトも元データと共有しないコピーを返す`cloneSettings`を実装してください。

## ルール

- `structuredClone()`を使う
- 元の`settings`を変更しない
- JSONへの変換は使わない
- 戻り値の外側・`theme`・`notifications.channels`が、すべて元とは別の参照になるようにする

## 入出力例

```js
const settings = {
  theme: {
    mode: "dark",
    fontSize: 16,
  },
  notifications: {
    enabled: true,
    channels: ["email", "push"],
  },
};

const copied = cloneSettings(settings);

copied.theme.mode = "light";
copied.notifications.channels.push("sms");

console.log(settings.theme.mode);
// "dark"

console.log(settings.notifications.channels);
// ["email", "push"]

console.log(copied === settings);
// false

console.log(copied.theme === settings.theme);
// false

console.log(
  copied.notifications.channels === settings.notifications.channels,
);
// false
```

## 考えるポイント

- `{ ...settings }`だけでは、内側の`theme`や`notifications`は共有される
- 今回は一部分の更新ではなく、データ全体を独立して複製する
- `structuredClone()`の戻り値を、そのまま関数の戻り値にできる

## 補足

`structuredClone()`は多くのデータを深くコピーできますが、関数などコピーできない値もあります。今回は文字列、数値、真偽値、配列、通常のオブジェクトだけを扱います。
