# Unit 10：参照・コピー・イミュータブルな更新

**状態：進行中**

## 学習項目

- プリミティブ値とオブジェクトの代入の違い
- オブジェクト・配列の参照共有
- `===`による同一参照の判定
- スプレッド構文による浅いコピー
- 元データを変更しない更新
- ネストしたオブジェクトのコピー
- `structuredClone()`の基礎

## 累積復習

- オブジェクトのプロパティ操作
- 分割代入とプロパティの省略記法
- `map`・`reduce`
- 動的なキーによる集計

## 完了条件

- 代入によって参照が共有されるケースを説明できる
- 元データを変更せず、オブジェクトと配列を更新できる
- 浅いコピーではネストした値が共有されることを説明できる
- ネストした階層を必要な深さまでコピーできる
- 浅いコピーと深いコピーを用途に応じて選べる
