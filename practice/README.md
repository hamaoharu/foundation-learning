# STEP 4：演習

学習計画が確定しました。次回からUnit 1の演習を1問ずつ配置します。

## 運用

- 問題は`unitXX/questions/`へ配置する
- 回答は`unitXX/answers/`へ記入する
- 採点と解説は`unitXX/reviews/`へ記録する
- 完了条件を満たした単元だけ完了にする
- 新しい単元の問題内に、完了済み単元の知識を組み込んで復習する
- 採点では、新単元の習得度と過去単元の維持状況を分けて記録する
- 過去単元の失敗が続いた場合は、その単元を要復習へ戻す
- 学習内容と完了条件はペースに応じて削減しない
- 1問だけで止めても、複数タスク進めてもよい
- 終了時に次回の再開位置と残りの完了条件を記録する
