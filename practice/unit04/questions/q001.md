# Unit 4 / Q001：文字列メソッドの戻り値

教材を一度読んだ後は見返さず、コードも実行せずに回答してください。

## 問題

次のA〜Hについて、結果と戻り値の型を書いてください。

```js
console.log("A", "  Alice  ".trim());
console.log("B", "HELLO".toLowerCase());
console.log("C", "JavaScript".includes("Script"));
console.log("D", "JavaScript".includes("script"));
console.log("E", "JavaScript".slice(0, 4));
console.log("F", "red,green,blue".split(","));
console.log("G", ["red", "green", "blue"].join("-"));
console.log("H", "a-b-c".replace("-", "/"));
```

型は`string`、`boolean`、`array`のいずれかで回答してください。
