# Unit 4 / Q003：連絡先情報を整形する

## 問題

連絡先を表すプレーンオブジェクト`contact`を受け取り、表示用の新しいプレーンオブジェクトを返す`createContactSummary`を実装してください。

入力例：

```js
const contact = {
  name: "  Alice Smith  ",
  email: "  ALICE@EXAMPLE.COM ",
  note: "  Important customer  ",
};
```

返却形式：

```js
{
  name: "Alice Smith",
  email: "alice@example.com",
  username: "alice",
  note: "Important customer",
}
```

ルール：

- `name`の前後の空白を削除する
- `email`の前後の空白を削除し、小文字にする
- 整形後のメールアドレスを`@`で分割し、前半を`username`にする
- `note`が文字列なら前後の空白を削除する
- `note`が存在しない、`null`、または空白だけなら`"メモなし"`にする
- optional chainingと、適切な論理演算子を使う
- 元の`contact`を変更しない

確認例：

```js
createContactSummary({
  name: " Bob ",
  email: " BOB@MAIL.TEST ",
});
// {
//   name: "Bob",
//   email: "bob@mail.test",
//   username: "bob",
//   note: "メモなし",
// }

createContactSummary({
  name: " Carol ",
  email: " CAROL@MAIL.TEST ",
  note: "   ",
});
// noteは"メモなし"
```

正しい形式のメールアドレスだけが渡されるものとします。
