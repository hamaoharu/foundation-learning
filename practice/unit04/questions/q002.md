# Unit 4 / Q002：アカウント情報を整形する

## 問題

`firstName`、`lastName`、`email`を受け取り、次の形の新しいプレーンオブジェクトを返す`createAccountInfo`を実装してください。

```js
{
  displayName: "Taro Yamada",
  email: "taro@example.com",
  domain: "example.com",
}
```

ルール：

- `firstName`と`lastName`の前後の空白を`trim()`で削除する
- 整形した姓名を半角スペース1つで結合し、`displayName`にする
- `email`の前後の空白を削除し、すべて小文字にする
- 整形後のメールアドレスを`@`で`split()`し、後半を`domain`にする
- 元の引数を変更しない

## 入出力例

```js
createAccountInfo(
  "  Taro ",
  " Yamada  ",
  "  TARO@EXAMPLE.COM ",
);

// {
//   displayName: "Taro Yamada",
//   email: "taro@example.com",
//   domain: "example.com",
// }
```

正しい形式のメールアドレスだけが渡されるものとします。
