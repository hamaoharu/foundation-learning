# Unit 4 / Q004：記事情報を整形する

## 問題

記事タイトル`title`、本文`body`、検索語`keyword`を受け取り、次の形の新しいプレーンオブジェクトを返す`createArticleSummary`を実装してください。

```js
{
  slug: string,
  preview: string,
  containsKeyword: boolean,
}
```

## ルール

### `slug`

1. `title`の前後の空白を削除する
2. すべて小文字にする
3. 含まれる半角スペースをすべて`"-"`へ置換する

```js
"  Learn JavaScript Basics  "
// "learn-javascript-basics"
```

### `preview`

1. `body`の前後の空白を削除する
2. 整形後の本文が20文字以下なら、そのまま使用する
3. 20文字を超えるなら、先頭20文字を`slice()`で取り出し、末尾に`"..."`を付ける

### `containsKeyword`

- 整形後の本文が`keyword`を含むか`includes()`で判定する
- 大文字・小文字を区別せずに判定する

## 入出力例

```js
createArticleSummary(
  "  Learn JavaScript Basics  ",
  "  JavaScript is useful for building web applications.  ",
  "javascript",
);

// {
//   slug: "learn-javascript-basics",
//   preview: "JavaScript is useful...",
//   containsKeyword: true,
// }
```

```js
createArticleSummary(
  " Short Post ",
  " Hello world ",
  "WORLD",
);

// {
//   slug: "short-post",
//   preview: "Hello world",
//   containsKeyword: true,
// }
```

## 条件

- `replaceAll()`、`slice()`、`includes()`を使う
- 元の引数は変更しない
- 必要に応じて中間結果を`const`で保存する

## 累積復習

- 関数とreturn
- 条件分岐
- boolean
- 新しいプレーンオブジェクトの生成
