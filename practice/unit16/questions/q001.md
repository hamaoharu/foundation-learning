# Unit 16 / Q001：Promiseの状態と`then()`の戻り値

## 問題

次のコードを実行せずに読み、問1〜問5へ答えてください。

```js
const firstPromise = Promise.resolve(5);

const secondPromise = firstPromise.then((value) => {
  return value * 2;
});

secondPromise.then((value) => {
  console.log(value);
});
```

## 問1

`firstPromise`は通常の数値ですか、それともPromiseですか。

## 問2

`firstPromise`は最終的にどの状態になり、成功値はいくつですか。

## 問3

最初の`then()`のcallbackに渡される`value`はいくつですか。

## 問4

`secondPromise`は通常の数値ですか、それともPromiseですか。また、最終的な成功値はいくつですか。

## 問5

`console.log(value)`に表示される値はいくつですか。
