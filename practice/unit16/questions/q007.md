# Unit 16 / Q007：最終統合問題—注文データを検証・集計する

## 問題

用意された`getOrders(mode)`が返すPromiseを使い、支払い済み注文の件数と合計金額を返す`summarizePaidOrders(mode, logs)`を実装してください。

## `getOrders(mode)`の動作

### `"success"`

注文配列でfulfilledになります。

```js
[
  { id: 1, status: "paid", price: 1200 },
  { id: 2, status: "pending", price: 800 },
  { id: 3, status: "paid", price: 2300 },
]
```

### `"invalid"`

配列ではないオブジェクトでfulfilledになります。

```js
{ message: "invalid data" }
```

### `"failure"`

`new Error("orders unavailable")`でrejectedになります。

## 成功時の結果

```js
const logs = [];
const promise = summarizePaidOrders("success", logs);

// 最終的な成功値
{
  count: 2,
  total: 3500,
}

// 処理完了後
logs;
// ["validated", "filtered", "summarized", "end"]
```

## 不正データ時の結果

配列でなければ、`then()`内で次のエラーをthrowしてください。

```js
throw new TypeError("orders must be an array");
```

`catch()`で回復した最終的な成功値：

```js
{
  count: 0,
  total: 0,
  error: "TypeError: orders must be an array",
}
```

ログ：

```js
["error", "end"]
```

## 取得失敗時の結果

`catch()`で回復した最終的な成功値：

```js
{
  count: 0,
  total: 0,
  error: "Error: orders unavailable",
}
```

ログ：

```js
["error", "end"]
```

## 実装の順序

1. `getOrders(mode)`からPromise chainを始める
2. 1つ目の`then()`で`Array.isArray()`による検証を行う
3. 配列なら`"validated"`を追加して注文配列をreturnする
4. 2つ目の`then()`で`status === "paid"`の注文を`filter()`する
5. `"filtered"`を追加して抽出配列をreturnする
6. 3つ目の`then()`で`reduce()`を使って合計を求める
7. `"summarized"`を追加し、件数と合計のオブジェクトをreturnする
8. `catch()`で`"error"`を追加し、エラー情報を含む代替オブジェクトをreturnする
9. `finally()`で`"end"`を追加する

## ルール

- Promise chain全体をreturnする
- `new Promise()`と`async/await`は使わない
- `getOrders`は変更しない
- 3つの`then()`へ検証・抽出・集計を分ける
- `reduce()`の初期値は`0`にする
- callbackで次へ渡す値を必ずreturnする
- 元の注文配列を変更しない
