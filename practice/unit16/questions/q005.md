# Unit 16 / Q005：`then/catch/finally`を実装する

## 問題

用意された`getScore(shouldSucceed)`は、引数に応じて成功または失敗するPromiseを返します。

この関数を使い、`formatScore(shouldSucceed, logs)`を実装してください。

## 用意された関数

```js
getScore(true);
// 成功値80でfulfilledになるPromise

getScore(false);
// Error("score unavailable")でrejectedになるPromise
```

## 成功時

```js
const logs = [];
const promise = formatScore(true, logs);
```

`promise`は最終的に次の文字列でfulfilledになります。

```text
Score: 80
```

処理完了後の`logs`：

```js
["success", "end"]
```

## 失敗時

```js
const logs = [];
const promise = formatScore(false, logs);
```

`catch()`で失敗から回復し、`promise`は最終的に次の文字列でfulfilledになります。

```text
Score: unavailable
```

処理完了後の`logs`：

```js
["error: score unavailable", "end"]
```

## 実装の仕様

- `getScore(shouldSucceed)`が返すPromiseへ処理をつなぐ
- `then()`では`logs`へ`"success"`を追加し、`Score: 成功値`をreturnする
- `catch()`では`logs`へ`error: エラーメッセージ`を追加し、`"Score: unavailable"`をreturnする
- `finally()`では`logs`へ`"end"`を追加する
- `formatScore`からPromise chain全体をreturnする

## ルール

- `new Promise()`は使わない
- `async/await`はまだ使わない
- `getScore`は変更しない
- `finally()`から値をreturnしない
- `formatScore`を名前付きexportする
