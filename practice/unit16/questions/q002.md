# Unit 16 / Q002：Promise chainとreturnを読む

## 問題

次のコードを実行せずに読み、問1〜問5へ答えてください。

```js
Promise.resolve(4)
  .then((value) => {
    return value + 1;
  })
  .then((value) => {
    console.log(value); // ①
  })
  .then((value) => {
    console.log(value); // ②
  });
```

## 問1

最初の`then()`が受け取る`value`はいくつですか。

## 問2

最初の`then()`が返す新しいPromiseの最終的な成功値はいくつですか。

## 問3

①には何が表示されますか。

## 問4

②には何が表示されますか。

## 問5

②がその値になる理由を、2番目の`then()`のcallbackのreturnに触れて説明してください。
