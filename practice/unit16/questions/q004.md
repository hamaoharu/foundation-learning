# Unit 16 / Q004：同期処理と`then()`の表示順

## 問題

次のコードを実行せずに読み、問1〜問3へ答えてください。

```js
console.log("A");

Promise.resolve("B")
  .then((value) => {
    console.log(value);
    return "D";
  })
  .then((value) => {
    console.log(value);
  });

console.log("C");
```

## 問1

表示される内容を、実際の順番ですべて書いてください。

## 問2

Promiseはすでに`"B"`でfulfilledなのに、なぜ`"B"`より先に`"C"`が表示されますか。

## 問3

最後の`then()`へ`"D"`が渡るのはなぜですか。

## 回答時のルール

- 実行せずに答える
- 問2は「同期処理」と「thenのcallback」という言葉を使う
- 詳細なevent loopやmicrotaskの説明はまだ不要
- 資料を参照した場合は記録する
