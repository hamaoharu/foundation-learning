# Unit 16 / Q003：エラーの伝播と`catch()`後の回復

## 問題

次のコードを実行せずに読み、問1〜問6へ答えてください。

```js
Promise.resolve(10)
  .then((value) => {
    throw new Error(`failed: ${value}`);
  })
  .then((value) => {
    console.log(`A: ${value}`);
  })
  .catch((error) => {
    console.log(`B: ${error.message}`);
    return 0;
  })
  .then((value) => {
    console.log(`C: ${value}`);
  })
  .finally(() => {
    console.log("D: end");
  });
```

## 問1

最初の`then()`が受け取る`value`はいくつですか。

## 問2

最初の`then()`がthrowするErrorの`message`は何ですか。

## 問3

`A: ...`は表示されますか。表示される／されないの理由も書いてください。

## 問4

`B: ...`には何が表示されますか。

## 問5

`C: ...`には何が表示されますか。`catch()`のreturnに触れて理由も書いてください。

## 問6

最後に表示される内容は何ですか。
