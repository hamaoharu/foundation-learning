# Unit 16 / Q006：複数の`then()`で配列を加工する

## 問題

用意された`getUsers(shouldSucceed)`は、成功時にユーザー配列、失敗時にErrorを持つPromiseを返します。

この関数を使い、`getActiveUserNames(shouldSucceed, logs)`を実装してください。

## 成功時に得られるデータ

```js
[
  { id: 1, name: "  Haru  ", active: true },
  { id: 2, name: "Aki", active: false },
  { id: 3, name: "  Sora", active: true },
]
```

## 成功時の最終結果

```js
const logs = [];
const promise = getActiveUserNames(true, logs);

// promiseは最終的に次の値でfulfilledになる
["Haru", "Sora"]

// 処理完了後
logs;
// ["filtered", "mapped", "end"]
```

## 失敗時の最終結果

```js
const logs = [];
const promise = getActiveUserNames(false, logs);

// catchで回復し、最終的に次の値でfulfilledになる
[]

// 処理完了後
logs;
// ["error: users unavailable", "end"]
```

## 実装の仕様

1. `getUsers(shouldSucceed)`が返すPromiseからchainを始める
2. 1つ目の`then()`で`active`が`true`のユーザーだけを`filter()`する
3. `logs`へ`"filtered"`を追加し、抽出後の配列をreturnする
4. 2つ目の`then()`で各ユーザーの`name`を`trim()`した配列へ`map()`する
5. `logs`へ`"mapped"`を追加し、名前の配列をreturnする
6. `catch()`で`error: エラーメッセージ`を追加し、空配列をreturnする
7. `finally()`で`"end"`を追加する

## ルール

- Promise chain全体をreturnする
- `new Promise()`と`async/await`は使わない
- `getUsers`は変更しない
- 2つの`then()`を使い、抽出と変換を分ける
- 波括弧付きcallbackでは必要な値を明示的にreturnする
- 元のユーザー配列を変更しない
