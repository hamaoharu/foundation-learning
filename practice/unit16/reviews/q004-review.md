# Unit 16 / Q004 レビュー

## 判定

解説後合格。

## 確認できたこと

- 表示順を`A → C → B → D`と正しく判断できている
- 同期処理が先に実行され、`then()`のcallbackはその後に実行されると説明できている
- 最初の`then()`が`"D"`をreturnするため、次の`then()`へ`"D"`が渡ると判断できている

## 補足した点

Promiseは非同期処理そのものというより、非同期処理などの結果を扱う仕組み。`Promise.resolve()`には時間のかかる処理がなくても、`then()`のcallbackは現在の同期処理が終わった後に実行される。
