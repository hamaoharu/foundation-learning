## 必須の修正

`findIndex`が見つからない場合に返す`-1`は、`null`でも`undefined`でもない。

そのため、次の`?? null`では変換されない。

```js
-1 ?? null // -1
```

`??`が右側を選ぶのは、左側が`null`または`undefined`の場合だけ。

今回は`findIndex`の結果を変数へ保存し、その値が`-1`と厳密に一致するか判定して、`null`または添字を返す。

## 実行結果

```text
途中で発見 → 1
先頭で発見 → 0
不一致     → -1
空配列     → -1
```

期待する不一致・空配列の結果は`null`。

## 次の完了条件

- `findIndex`の結果を保存する
- `-1`だけを`null`へ変換する
- 添字`0`をそのまま返す
- 元データを変更しない

すべて達成した。
