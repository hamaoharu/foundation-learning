# Unit 7 / Q006：要件からメソッドを選ぶ

## 問題

各要件に最も適したメソッドを、次の5つから1つずつ選んでください。

```text
find / findIndex / some / every / includes
```

それぞれ、メソッド名と選んだ理由を短く書いてください。コードの実装は不要です。

### A

ユーザー配列から、メールアドレスが一致する最初のユーザーオブジェクトを取得したい。

### B

商品配列の中に、価格が10万円を超える商品が1件でもあるか確認したい。

### C

入力値が、文字列配列`["small", "medium", "large"]`のどれかと一致するか確認したい。

### D

フォーム項目の配列について、すべての項目が入力済みか確認したい。

### E

タスク配列から、最初の未完了タスクが何番目にあるか取得したい。
