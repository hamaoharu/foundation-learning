# Unit 7 / Q001：IDからユーザーを探す

## 問題

ユーザーオブジェクトの配列`users`と数値`targetId`を受け取り、`id`が一致する最初のユーザーオブジェクトを返す`findUserById`を実装してください。

一致するユーザーがいない場合は`null`を返してください。

## ルール

- `find`を使う
- `filter`、`for`、`for...of`、`forEach`は使わない
- IDは`===`で比較する
- 元の配列とユーザーオブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
const users = [
  { id: 1, name: "Haru" },
  { id: 2, name: "Sora" },
];

findUserById(users, 2);
// { id: 2, name: "Sora" }

findUserById(users, 9);
// null

findUserById([], 1);
// null
```

## 考えるポイント

- `find`自身が見つからなかったときに返す値
- 問題で指定された`null`へどう変換するか
- `0`や空文字を残す必要はなく、対象はユーザーオブジェクトか`undefined`

## 累積復習

- コールバックと`return`
- 厳密等価比較
- `undefined`と`null`
- `??`によるデフォルト値
