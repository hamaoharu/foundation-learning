# Unit 7 / Q005：許可された権限か判定する

## 問題

許可された権限名の文字列配列`allowedRoles`と、確認対象の文字列`role`を受け取り、`role`が配列に含まれていれば`true`、含まれていなければ`false`を返す`isAllowedRole`を実装してください。

## ルール

- `includes`を使う
- `some`、`find`、`filter`、`for`、`for...of`、`forEach`は使わない
- 大文字・小文字は区別する
- 元の配列を変更しない

## 入出力例

```js
isAllowedRole(["admin", "editor", "viewer"], "editor");
// true

isAllowedRole(["admin", "editor", "viewer"], "guest");
// false

isAllowedRole(["admin"], "Admin");
// false

isAllowedRole([], "admin");
// false
```

## 考えるポイント

- `includes`はコールバックを受け取らない
- 引数で指定した値そのものを含むか判定する
- `includes`自身がBooleanを返す

## 累積復習

- 厳密な値の比較
- 大文字・小文字の違い
- 配列メソッド全体の戻り値
