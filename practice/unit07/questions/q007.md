# Unit 7 / Q007：初見総合—商品一覧の状態を調べる

## 問題

商品オブジェクトの配列`products`と数値`targetId`を受け取り、次の形の新しいオブジェクトを返す`inspectProducts`を実装してください。

```js
{
  targetProduct: targetIdと一致する最初の商品。なければnull,
  hasOutOfStock: 在庫0の商品が1件でもあればtrue,
  allPublished: すべての商品が公開中ならtrue,
}
```

## ルール

- `targetProduct`には`find`を使う
- `hasOutOfStock`には`some`を使う
- `allPublished`には`every`を使う
- `filter`、`for`、`for...of`、`forEach`は使わない
- 各コールバックで波括弧と`return`を明示する
- 元の配列と商品オブジェクトを変更しない
- 空配列では次を返す

```js
{
  targetProduct: null,
  hasOutOfStock: false,
  allPublished: true,
}
```

## 入出力例

```js
const products = [
  { id: 1, name: "Keyboard", stock: 3, isPublished: true },
  { id: 2, name: "Mouse", stock: 0, isPublished: true },
  { id: 3, name: "Monitor", stock: 2, isPublished: false },
];

inspectProducts(products, 2);
// {
//   targetProduct: { id: 2, name: "Mouse", stock: 0, isPublished: true },
//   hasOutOfStock: true,
//   allPublished: false,
// }

inspectProducts(products, 9);
// {
//   targetProduct: null,
//   hasOutOfStock: true,
//   allPublished: false,
// }
```

## 完了判定

- 要素が必要な処理で`find`を使える
- 存在判定で`some`を使える
- 全件判定で`every`を使える
- 各メソッドの戻り値を新しいオブジェクトへまとめられる
- 不一致と空配列を仕様どおりに処理できる
