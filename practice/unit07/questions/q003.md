# Unit 7 / Q003：在庫切れ商品があるか判定する

## 問題

商品オブジェクトの配列`products`を受け取り、`stock`が`0`の商品が1つでも存在する場合は`true`、存在しない場合は`false`を返す`hasOutOfStockProduct`を実装してください。

## ルール

- `some`を使う
- `find`、`filter`、`for`、`for...of`、`forEach`は使わない
- 元の配列と商品オブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
hasOutOfStockProduct([
  { id: 1, stock: 3 },
  { id: 2, stock: 0 },
]);
// true

hasOutOfStockProduct([
  { id: 1, stock: 3 },
  { id: 2, stock: 1 },
]);
// false

hasOutOfStockProduct([]);
// false
```

## 考えるポイント

- コールバックから返すBoolean
- `some`自身もBooleanを返す
- 空配列では、条件を満たす要素が1つもないため`false`

## 累積復習

- 比較式
- コールバックと`return`
- 配列メソッド全体の戻り値
