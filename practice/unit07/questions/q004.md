# Unit 7 / Q004：すべてのユーザーが認証済みか判定する

## 問題

ユーザーオブジェクトの配列`users`を受け取り、すべてのユーザーの`isVerified`が`true`なら`true`、1人でも`false`なら`false`を返す`areAllUsersVerified`を実装してください。

## ルール

- `every`を使う
- `some`、`find`、`filter`、`for`、`for...of`、`forEach`は使わない
- 元の配列とユーザーオブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する
- 空配列に対しては、`every`の標準動作どおり`true`を返す

## 入出力例

```js
areAllUsersVerified([
  { id: 1, isVerified: true },
  { id: 2, isVerified: true },
]);
// true

areAllUsersVerified([
  { id: 1, isVerified: true },
  { id: 2, isVerified: false },
]);
// false

areAllUsersVerified([]);
// true
```

## 考えるポイント

- コールバックは各ユーザーが条件を満たすか返す
- `every`は1件でも`false`を見つけると`false`を返す
- 空配列では条件に違反する要素がないため`true`になる
