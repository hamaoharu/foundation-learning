# Unit 7 / Q002：未完了タスクの位置を探す

## 問題

タスクオブジェクトの配列`tasks`を受け取り、`isDone`が`false`である最初のタスクの添字を返す`findFirstIncompleteIndex`を実装してください。

未完了タスクがない場合は`null`を返してください。

## ルール

- `findIndex`を使う
- `find`、`filter`、`for`、`for...of`、`forEach`は使わない
- 元の配列とタスクオブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
findFirstIncompleteIndex([
  { id: 1, isDone: true },
  { id: 2, isDone: false },
  { id: 3, isDone: false },
]);
// 1

findFirstIncompleteIndex([
  { id: 1, isDone: false },
  { id: 2, isDone: true },
]);
// 0

findFirstIncompleteIndex([
  { id: 1, isDone: true },
]);
// null

findFirstIncompleteIndex([]);
// null
```

## 考えるポイント

- `findIndex`が見つからない場合に返す値
- 添字`0`は正常な検索結果なので、falsyとして不一致扱いしない
- `findIndex`の結果を変数へ保存し、見つからない値かどうかを厳密に判定する

## 累積復習

- コールバックと`return`
- Booleanプロパティ
- 厳密等価比較
- 条件分岐
- `null`
