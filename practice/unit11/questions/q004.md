# Unit 11 / Q004：Mapで出現回数を数える

## 問題

文字列の配列`words`を受け取り、各文字列の出現回数を保存した`Map`を返す`countWords`を実装してください。

## ルール

- 空の`Map`を作る
- `for...of`を使う
- 現在の件数の取得に`get()`を使う
- 件数の保存に`set()`を使う
- 初登場の文字列は`0`件として扱い、そこから1増やす
- `reduce()`は使わない

## 入出力例

```js
const counts = countWords(["js", "css", "js", "html", "js", "css"]);

console.log(counts);
// Map(3) {
//   "js" => 3,
//   "css" => 2,
//   "html" => 1
// }

console.log(counts.get("js"));
// 3

console.log(counts.get("react"));
// undefined

countWords([]);
// Map(0) {}
```

## 考えるポイント

各`word`について、次の処理を繰り返します。

```text
現在の件数を取得する
  ↓
未登録なら0として扱う
  ↓
1を足した件数を同じキーへ保存する
```

オブジェクトによる頻度表では次の形を使いました。

```js
counts[key] = (counts[key] ?? 0) + 1;
```

Mapではブラケット記法の代わりに、`get()`と`set()`を使います。

## 累積復習

- 頻度表
- `??`による初期値
- `for...of`
- 同じキーの値を更新する処理
