# Unit 11 / Q001：重複を除いた配列を作る

## 問題

文字列の配列`tags`を受け取り、重複を除いた**新しい配列**を返す`getUniqueTags`を実装してください。

最初に登場した順序を維持してください。

## ルール

- `Set`を使う
- 配列のスプレッド構文を使う
- `filter()`や`indexOf()`は使わない
- 元の`tags`を変更しない

## 入出力例

```js
const tags = ["JavaScript", "React", "JavaScript", "CSS", "React"];

getUniqueTags(tags);
// ["JavaScript", "React", "CSS"]

getUniqueTags([]);
// []
```

## 考えるポイント

1. `tags`を`Set`のコンストラクタへ渡す
2. 作られた`Set`を、新しい配列の中へスプレッドする

## 累積復習

- 配列のスプレッド構文
- 新しい配列を返す処理
- 元データを変更しない処理
