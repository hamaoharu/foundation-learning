# Unit 11 / Q007：JSON文字列をオブジェクトへ変換する

## 問題

ユーザー情報を表す正しいJSON文字列`json`を受け取り、JavaScriptの値へ変換して返す`parseUser`を実装してください。

この問題では、引数には必ず正しいJSON文字列が渡されるものとします。

## ルール

- `JSON.parse()`を使う
- 手作業でオブジェクトを組み立てない
- 戻り値は文字列ではなく、解析後のJavaScriptの値にする

## 入出力例

```js
const json = '{"id":1,"name":"Haru","active":true}';
const user = parseUser(json);

console.log(user);
// { id: 1, name: "Haru", active: true }

console.log(typeof user);
// "object"

console.log(user.name);
// "Haru"
```

配列を表すJSONにも、そのまま対応します。

```js
parseUser('["JavaScript","CSS"]');
// ["JavaScript", "CSS"]
```

## 考えるポイント

`JSON.parse()`が返す値は、JSONの内容によって変わります。

```text
JSONのオブジェクト → JavaScriptのオブジェクト
JSONの配列         → JavaScriptの配列
JSONの数値         → JavaScriptの数値
```

## 累積復習

- 文字列とオブジェクトの違い
- 関数の戻り値
- 配列もオブジェクトの一種であること
