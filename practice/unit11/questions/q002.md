# Unit 11 / Q002：選択済みIDをSetで調べる

## 問題

選択済みIDの配列`selectedIds`と、確認したいID`targetId`を受け取り、次の情報を持つオブジェクトを返す`analyzeSelection`を実装してください。

```js
{
  hasTarget: targetIdが含まれているか,
  uniqueCount: 重複を除いたIDの個数,
}
```

## ルール

- `selectedIds`から`Set`を1つ作る
- 含まれているかの確認には`has()`を使う
- 個数の取得には`size`を使う
- `includes()`や`length`は使わない
- 元の配列を変更しない

## 入出力例

```js
analyzeSelection([1, 2, 2, 3], 2);
// {
//   hasTarget: true,
//   uniqueCount: 3,
// }

analyzeSelection([1, 2, 2, 3], 5);
// {
//   hasTarget: false,
//   uniqueCount: 3,
// }

analyzeSelection([], 1);
// {
//   hasTarget: false,
//   uniqueCount: 0,
// }
```

## 考えるポイント

- `set.has(targetId)`は真偽値を返す
- `set.size`はプロパティなので、`size()`とは書かない
- 返すオブジェクトの値には、式の結果をそのまま指定できる

## 累積復習

- オブジェクトを返す関数
- 真偽値
- メソッドとプロパティの違い
- 重複除去
