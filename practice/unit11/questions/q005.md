# Unit 11 / Q005：Mapを表示用の配列へ変換する

## 問題

文字列をキー、数値を値として持つ`Map`の`counts`を受け取り、各要素を`"キー: 値"`形式の文字列へ変換した配列を返す`formatCounts`を実装してください。

Mapへ登録された順序を維持してください。

## ルール

- 結果を入れる空配列を作る
- `for...of`を使う
- 分割代入で`key`と`value`を受け取る
- `push()`で結果配列へ追加する
- テンプレートリテラルを使う
- `Map`を変更しない

## 入出力例

```js
const counts = new Map([
  ["js", 3],
  ["css", 2],
  ["html", 1],
]);

formatCounts(counts);
// ["js: 3", "css: 2", "html: 1"]

formatCounts(new Map());
// []
```

## 考えるポイント

Mapを`for...of`で繰り返すと、各周回では`[キー, 値]`の組を受け取ります。

```js
for (const [key, value] of counts) {
  // keyとvalueを使える
}
```

`push()`は結果用の新しい配列を変更します。入力の`counts`を変更しているわけではないため、今回の用途では問題ありません。

## 累積復習

- `for...of`
- 配列の`push()`
- 配列の分割代入
- テンプレートリテラル
- 入力を変更しない処理
