# Unit 11 / Q003：MapからIDに対応する名前を取得する

## 問題

ユーザー配列`users`と対象ID`targetId`を受け取り、ユーザーIDをキー、ユーザー名を値とする`Map`を作ってから、対象ユーザーの名前を返す`getUserNameById`を実装してください。

対象IDが存在しない場合は`null`を返してください。

## ルール

- 空の`Map`を作る
- `for...of`でユーザー配列を繰り返す
- `set()`でIDと名前を保存する
- `get()`で対象IDの名前を取得する
- 存在しない場合の処理には`??`を使う
- `find()`は使わない

## 入出力例

```js
const users = [
  { id: 1, name: "Haru" },
  { id: 2, name: "Aki" },
];

getUserNameById(users, 2);
// "Aki"

getUserNameById(users, 99);
// null

getUserNameById([], 1);
// null
```

## 考えるポイント

```js
const userMap = new Map();
```

各ユーザーについて、次の対応を保存します。

```text
user.id → user.name
```

保存後、`targetId`をキーとして値を取得します。

## 累積復習

- `for...of`
- オブジェクトのプロパティ取得
- `??`によるデフォルト値
- 空配列への対応
