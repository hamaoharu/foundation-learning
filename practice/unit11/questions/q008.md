# Unit 11 / Q008：JSON変換の注意点を読む

## 問題

次のコードを**実行せずに**読み、問1〜問4へ回答してください。

```js
const source = {
  name: "Haru",
  age: undefined,
  greet() {
    return "hello";
  },
  skills: ["JavaScript", "CSS"],
};

const json = JSON.stringify(source);
const parsed = JSON.parse(json);
```

## 問1

`typeof json`の結果を書いてください。

## 問2

`json`の内容を書いてください。

空白は含めず、`JSON.stringify()`が返す形で記述してください。

## 問3

次の3つの結果を書いてください。

```js
parsed.name
parsed.age
parsed.greet
```

## 問4

次のコードを実行すると、値が返るか、エラーが発生するかを書いてください。エラーになる場合は、分かればエラーの種類も書いてください。

```js
JSON.parse("not json");
```

## 考えるポイント

- `JSON.stringify()`の戻り値は文字列
- オブジェクト内の`undefined`や関数はJSONへ変換すると省略される
- 存在しないプロパティを読むと`undefined`になる
- 不正なJSON文字列は解析できない
