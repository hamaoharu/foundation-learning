# Unit 11 / Q006：オブジェクトをJSON文字列へ変換する

## 問題

ユーザーオブジェクト`user`を受け取り、JSON文字列へ変換して返す`serializeUser`を実装してください。

## ルール

- `JSON.stringify()`を使う
- 元の`user`を変更しない
- 手作業で文字列を組み立てない
- 戻り値はオブジェクトではなく文字列にする

## 入出力例

```js
const user = {
  id: 1,
  name: "Haru",
  active: true,
  skills: ["JavaScript", "CSS"],
};

const json = serializeUser(user);

console.log(json);
// '{"id":1,"name":"Haru","active":true,"skills":["JavaScript","CSS"]}'

console.log(typeof json);
// "string"
```

空のオブジェクトにも対応してください。

```js
serializeUser({});
// "{}"
```

## 考えるポイント

次の2つは見た目が似ていますが、データ型が異なります。

```js
const object = { id: 1 };     // object
const json = '{"id":1}';     // string
```

`JSON.stringify()`は、JavaScriptの値をJSON形式の文字列へ変換して返します。

## 累積復習

- 関数の戻り値
- オブジェクトと文字列の違い
- 元データを変更しない処理
