# Unit 11 / Q009：JSON・Set・Mapの総合処理

## 問題

タグ配列を表す正しいJSON文字列`json`を受け取り、タグを分析したオブジェクトを返す`analyzeTagsJson`を実装してください。

戻り値は次の形にします。

```js
{
  uniqueTags: 重複を除いたタグ配列,
  counts: タグごとの件数を持つMap,
  labels: 「タグ: 件数」形式の文字列配列,
}
```

## ルール

- `JSON.parse()`でJSON文字列を配列へ変換する
- `Set`と配列のスプレッド構文で`uniqueTags`を作る
- 空の`Map`と`for...of`で件数を集計する
- Mapの現在値は`get()`、保存は`set()`で行う
- `labels`はMapを`for...of`で繰り返して作る
- Mapの繰り返しでは`[tag, count]`の分割代入を使う
- `push()`で`labels`へ文字列を追加する

## 入出力例

```js
const result = analyzeTagsJson(
  '["JavaScript","CSS","JavaScript","HTML","CSS"]',
);

console.log(result.uniqueTags);
// ["JavaScript", "CSS", "HTML"]

console.log(result.counts);
// Map(3) {
//   "JavaScript" => 2,
//   "CSS" => 2,
//   "HTML" => 1
// }

console.log(result.labels);
// ["JavaScript: 2", "CSS: 2", "HTML: 1"]
```

空配列を表すJSONにも対応してください。

```js
analyzeTagsJson("[]");
// {
//   uniqueTags: [],
//   counts: Map(0) {},
//   labels: [],
// }
```

## 処理を分解する

1. JSON文字列をタグ配列へ変換する
2. タグ配列から重複を除いた配列を作る
3. タグ配列を繰り返し、Mapへ件数を保存する
4. Mapを繰り返し、表示用文字列の配列を作る
5. 3つの結果をオブジェクトとして返す
