# Unit 11 / Q005 レビュー

## 判定

合格。

## 確認できたこと

- Mapを`for...of`で繰り返せている
- 取り出した`[key, value]`を配列の分割代入で受け取れている
- テンプレートリテラルで表示用文字列を作れている
- `push()`で結果用配列へ追加できている
- 空のMapでは空配列を返せる

## 要復習

Map本体は配列ではないが、Mapを繰り返したときの各要素は`[キー, 値]`の組として受け取れる。この「全体の型」と「取り出される1件の形」の違いに混乱があったため、後続問題でも再確認する。

```js
for (const [key, value] of map) {
  // Mapから取り出した1件を分割している
}
```
