## 必須の修正

### 1. 配列には配列の分割代入を使う

`Object.entries()`の各要素は、次のような配列。

```js
["todo", 3]
```

現在の`const { key, value } = array`はオブジェクトの分割代入であり、`key`と`value`というプロパティを探すため、両方`undefined`になる。

配列の0番目と1番目を取り出す場合は、角括弧の分割代入を使う。

また、コールバック引数で直接分割代入できる。

### 2. `map`が返した配列を外側の関数からreturnする

現在は`Object.entries(...).map(...)`を実行しているが、その結果を`formatCounts`から返していない。そのため関数全体の戻り値が`undefined`になる。

```text
内側のreturn → mapへ各文字列を返す
外側のreturn → mapが作った文字列配列を呼び出し元へ返す
```

## 実行結果

```text
すべてのケース → undefined
```

## 次の完了条件

- コールバック引数で`[key, value]`を分割代入する
- 各文字列を`map`へ返す
- `map`全体の配列を`formatCounts`から返す
- 空オブジェクトでは空配列を返す

すべて達成した。
