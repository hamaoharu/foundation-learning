# Unit 9 / Q004：プロパティを別名の変数へ取り出す

## 問題

ユーザーオブジェクト`user`を受け取り、分割代入で次のように取り出してください。

- `name`プロパティ → `displayName`変数
- `plan`プロパティ → `planName`変数
- `plan`が`undefined`の場合、`planName`のデフォルト値は`"free"`

その後、次の形の新しいオブジェクトを返す`createDisplayUser`を実装してください。

```js
{
  displayName,
  planName,
}
```

## ルール

- 分割代入の別名構文`元のプロパティ名: 新しい変数名`を使う
- `planName`のデフォルト値も分割代入内に書く
- 返却オブジェクトではプロパティ省略記法を使う
- `user.name`や`user.plan`を直接使わない
- 元のユーザーオブジェクトを変更しない

## 入出力例

```js
createDisplayUser({ name: "Haru", plan: "pro" });
// { displayName: "Haru", planName: "pro" }

createDisplayUser({ name: "Sora" });
// { displayName: "Sora", planName: "free" }

createDisplayUser({ name: "Ren", plan: "" });
// { displayName: "Ren", planName: "" }
```

## 考えるポイント

```text
name: displayName
```

は、`name`プロパティを取得して`displayName`変数を作るという意味です。

別名とデフォルト値を同時に使う場合は、次の順番になります。

```text
元のプロパティ名: 新しい変数名 = デフォルト値
```
