# Unit 9 / Q007：初見総合—投票結果を集計して表示する

## 問題

投票内容の文字列配列`votes`を受け取り、次の形の新しいオブジェクトを返す`createVoteSummary`を実装してください。

```js
{
  counts: 投票内容ごとの件数オブジェクト,
  labels: countsを「投票内容: 件数」形式へ変換した文字列配列,
}
```

## ルール

- `counts`は`reduce`で作る
- `reduce`の初期値は空オブジェクト
- 投票内容を動的なキーとしてブラケット記法で扱う
- 未登録の件数には`?? 0`を使う
- `labels`は`Object.entries(counts)`と`map`で作る
- `map`のコールバック引数で`[key, value]`を分割代入する
- `for`、`for...of`、`forEach`は使わない
- 元の配列を変更しない
- 最後はプロパティ省略記法で`{ counts, labels }`を返す
- まず教材と過去の回答を見ずに実装する

## 入出力例

```js
createVoteSummary(["yes", "no", "yes", "pending", "yes", "no"]);
// {
//   counts: { yes: 3, no: 2, pending: 1 },
//   labels: ["yes: 3", "no: 2", "pending: 1"],
// }

createVoteSummary([]);
// {
//   counts: {},
//   labels: [],
// }
```

## 考える順番

1. `reduce`で`counts`を完成させる
2. 完成した`counts`を`Object.entries()`へ渡す
3. entriesを`map`で文字列へ変換する
4. `counts`と`labels`を新しいオブジェクトへまとめる

## 完了判定

- 動的キーによる頻度表を自力で作れる
- entriesの配列を分割代入できる
- 複数段階の変換を小さな変数へ分けられる
- 空配列を初期値から自然に処理できる
