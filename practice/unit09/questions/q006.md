# Unit 9 / Q006：在庫オブジェクトを3つの形で取得する

## 問題

商品名をキー、在庫数を値として持つオブジェクト`stockByProduct`を受け取り、次の形の新しいオブジェクトを返す`analyzeStockObject`を実装してください。

```js
{
  productNames: キーの配列,
  stockCounts: 値の配列,
  entries: [キー, 値]の配列,
}
```

## ルール

- `productNames`には`Object.keys()`を使う
- `stockCounts`には`Object.values()`を使う
- `entries`には`Object.entries()`を使う
- 元のオブジェクトを変更しない
- 返却時にはプロパティ省略記法を使う

## 入出力例

```js
analyzeStockObject({ Keyboard: 3, Mouse: 0, Monitor: 2 });
// {
//   productNames: ["Keyboard", "Mouse", "Monitor"],
//   stockCounts: [3, 0, 2],
//   entries: [
//     ["Keyboard", 3],
//     ["Mouse", 0],
//     ["Monitor", 2],
//   ],
// }

analyzeStockObject({});
// {
//   productNames: [],
//   stockCounts: [],
//   entries: [],
// }
```

## 考えるポイント

- `Object.keys()`はキーだけ
- `Object.values()`は値だけ
- `Object.entries()`は`[キー, 値]`の組
- どれも新しい配列を返す
