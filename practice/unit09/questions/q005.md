# Unit 9 / Q005：件数オブジェクトを表示文字列へ変換する

## 問題

項目ごとの件数を持つオブジェクト`counts`を受け取り、各プロパティを`"キー: 値"`形式の文字列へ変換した配列を返す`formatCounts`を実装してください。

## ルール

- `Object.entries()`を使う
- `map`を使う
- コールバック引数で配列の分割代入`[key, value]`を使う
- コールバック内で波括弧と`return`を明示する
- `for`、`for...of`、`forEach`は使わない
- 元のオブジェクトを変更しない

## 入出力例

```js
formatCounts({ todo: 3, done: 2, doing: 1 });
// ["todo: 3", "done: 2", "doing: 1"]

formatCounts({ error: 0 });
// ["error: 0"]

formatCounts({});
// []
```

## 考えるポイント

```js
Object.entries({ todo: 3, done: 2 });
```

の結果は次の二重配列です。

```js
[
  ["todo", 3],
  ["done", 2],
]
```

`map`の各回では、`["todo", 3]`のような1組を受け取ります。

```js
([key, value]) => {
  // keyは"todo"、valueは3
}
```

## 累積復習

- `Object.entries()`
- 配列の分割代入
- `map`
- テンプレートリテラル
- 空オブジェクトの扱い
