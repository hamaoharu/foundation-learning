# Unit 9 / Q001：指定されたプロパティを取得する

## 問題

ユーザーオブジェクト`user`と文字列`fieldName`を受け取り、`fieldName`で指定されたプロパティの値を返す`getUserField`を実装してください。

指定されたプロパティが存在せず、値が`undefined`の場合は`null`を返してください。

## ルール

- ブラケット記法を使う
- `if`や三項演算子は使わず、`??`を使う
- `fieldName`ごとの固定的な分岐を書かない
- 元のユーザーオブジェクトを変更しない

## 入出力例

```js
const user = {
  id: 1,
  name: "Haru",
  age: 20,
  nickname: "",
};

getUserField(user, "name");
// "Haru"

getUserField(user, "age");
// 20

getUserField(user, "nickname");
// ""

getUserField(user, "email");
// null
```

## 考えるポイント

- `fieldName`の中身が実際のキー名になる
- `user.fieldName`ではなく、変数の中身を使える記法が必要
- `||`では空文字が`null`へ変わるため、今回は`??`を使う

## 累積復習

- ブラケット記法
- `undefined`と`null`
- `??`と`||`の違い
- 元データを変更しない処理
