# Unit 9 / Q003：分割代入でユーザー表示を作る

## 問題

ユーザーオブジェクト`user`を受け取り、`name`と`role`を分割代入で取り出して、次の形式の文字列を返す`createUserLabel`を実装してください。

```text
名前 (権限)
```

`role`プロパティが存在せず`undefined`の場合は、分割代入のデフォルト値として`"guest"`を使用してください。

`name`は前後の空白を削除して表示します。

## ルール

- 関数内で分割代入を使う
- `role = "guest"`というデフォルト値を分割代入内に書く
- `user.name`や`user.role`を直接使わない
- 元のユーザーオブジェクトを変更しない

## 入出力例

```js
createUserLabel({ name: "  Haru ", role: "admin" });
// "Haru (admin)"

createUserLabel({ name: " Sora " });
// "Sora (guest)"

createUserLabel({ name: "Ren", role: "" });
// "Ren ()"
```

## 考えるポイント

- `{ name, role = "guest" }`は新しいオブジェクトではなく、変数を作るためのパターン
- デフォルト値は`role`が`undefined`の場合だけ使われる
- 空文字は`undefined`ではないため、そのまま維持される

## 累積復習

- 分割代入
- デフォルト値
- `trim()`
- テンプレートリテラル
- 元データを変更しない処理
