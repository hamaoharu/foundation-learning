# Unit 9 / Q002：動的なキーを持つオブジェクトを作る

## 問題

文字列`fieldName`と値`value`を受け取り、`fieldName`の中身をキー、`value`を値とする新しいオブジェクトを返す`createFieldObject`を実装してください。

## ルール

- オブジェクトリテラル内で計算されたプロパティ名`[fieldName]`を使う
- `if`や`switch`でキーごとの分岐を書かない
- 新しいオブジェクトを返す

## 入出力例

```js
createFieldObject("email", "haru@example.com");
// { email: "haru@example.com" }

createFieldObject("age", 20);
// { age: 20 }

createFieldObject("isActive", false);
// { isActive: false }
```

## 考えるポイント

次の書き方では、文字どおり`fieldName`という固定キーになります。

```js
{ fieldName: value }
```

変数`fieldName`の中身をキーとして使うには、オブジェクト生成時にもブラケットが必要です。

## 累積復習

- 動的キー
- オブジェクトリテラル
- 関数の引数と`return`
- falsy値もそのまま保存すること
