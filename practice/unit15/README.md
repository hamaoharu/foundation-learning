# Unit 15：例外処理とデバッグ

**状態：進行中**

## 学習項目

- エラーを読む順序
- `Error`オブジェクトと`name`・`message`・`stack`
- `SyntaxError`・`ReferenceError`・`TypeError`
- `throw`による入力検証
- `try`・`catch`・`finally`
- エラーを握りつぶさず、呼び出し元へ伝える考え方

## 累積復習

- 関数の引数・戻り値
- オブジェクトとoptional chaining
- 配列メソッド
- ES Modulesによる責務分割

- `try/catch/finally`で成功・失敗・後処理を扱える
- 必要なエラーを握りつぶさず、呼び出し元へ伝えられる
