# Unit 15 / Q004：`throw`で不正な入力を拒否する

## 問題

メールアドレス文字列を整形する`normalizeEmail(email)`を実装してください。

## 仕様

正常な入力では、前後の空白を取り除いて小文字にした文字列を返します。

```js
normalizeEmail("  HARU@EXAMPLE.COM  ");
// "haru@example.com"
```

次の不正な入力では、指定された例外をthrowしてください。

### 文字列以外

```js
normalizeEmail(123);
// TypeError: email must be a string
```

- `typeof email !== "string"`の場合
- `new TypeError("email must be a string")`をthrowする

### 空文字

```js
normalizeEmail("   ");
// Error: email is required
```

- `trim()`した結果が空文字の場合
- `new Error("email is required")`をthrowする

## ルール

- 不正な入力に`""`や`undefined`を返して済ませない
- `throw`の後に不要な`return`を書かない
- 正常な入力では文字列をreturnする
- 関数を名前付きexportする
- この問題ではまだ`try/catch`を書かない
