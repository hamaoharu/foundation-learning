# Unit 15 / Q003：JSON解析時の`SyntaxError`を特定する

## 問題

次のJavaScriptコードは文法として読み込めますが、実行するとエラーになります。実行せずに、エラー情報とコードを読んで答えてください。

```js
function parseSettings(jsonText) {
  return JSON.parse(jsonText);
}

const jsonText = '{"theme":"dark",}';
console.log(parseSettings(jsonText));
```

表示されたエラー：

```text
SyntaxError: Expected double-quoted property name in JSON at position 16
    at JSON.parse (<anonymous>)
    at parseSettings (app.mjs:2:15)
    at app.mjs:6:13
```
