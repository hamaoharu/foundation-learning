# Unit 15 / Q002：宣言されていない変数を特定する

## 問題

次のコードは実行時にエラーになります。実行せずに、エラー情報とコードを読んで答えてください。

```js
function createMessage(user) {
  return `${prefix}: ${user.name}`;
}

function printUser(user) {
  console.log(createMessage(user));
}

const user = { name: "Haru" };
printUser(user);
```

表示されたエラー：

```text
ReferenceError: prefix is not defined
    at createMessage (app.mjs:2:13)
    at printUser (app.mjs:6:15)
    at app.mjs:10:1
```

## 問1

エラーの種類は何ですか。

## 問2

最初に確認するべき行は何行目ですか。

## 問3

原因となった識別子（変数名）は何ですか。

## 問4

`prefix`には「値として`undefined`が入っている」のでしょうか。それとも「変数自体が宣言されていない」のでしょうか。

stack traceから、関数の呼び出し順を次の形式で書いてください。
