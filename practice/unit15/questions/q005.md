# Unit 15 / Q005：`try/catch`で成功と失敗を扱う

## 問題

Q004で作成した`normalizeEmail(email)`を使い、処理結果をオブジェクトで返す`getEmailResult(email)`を実装してください。

Q004の関数は、回答ファイルの先頭ですでにimportしてあります。

## 成功時

```js
getEmailResult("  HARU@EXAMPLE.COM  ");
```

次のオブジェクトを返します。

```js
{
  ok: true,
  email: "haru@example.com",
}
```

## 失敗時

```js
getEmailResult(123);
```

次のオブジェクトを返します。

```js
{
  ok: false,
  error: "TypeError: email must be a string",
}
```

空白だけの文字列では、次の結果になります。

```js
getEmailResult("   ");
// {
//   ok: false,
//   error: "Error: email is required",
// }
```

## ルール

- `try`内で`normalizeEmail(email)`を呼ぶ
- 成功時のオブジェクトは`try`内からreturnする
- `catch`で受け取った`error.name`と`error.message`を使う
- `catch`内から失敗時のオブジェクトをreturnする
- Q004の`normalizeEmail`自体は変更しない
- `getEmailResult`を名前付きexportする
