# Unit 15 / Q006：`finally`で必ず後処理する

## 問題

JSON文字列を解析し、処理の経過を`logs`配列へ記録する`parseJsonWithLog(jsonText, logs)`を実装してください。

## 成功時

```js
const logs = [];
const result = parseJsonWithLog('{"name":"Haru"}', logs);
```

期待する値：

```js
result;
// { name: "Haru" }

logs;
// ["start", "success", "end"]
```

## 失敗時

```js
const logs = [];
const result = parseJsonWithLog("not json", logs);
```

期待する値：

```js
result;
// null

logs;
// ["start", "error: SyntaxError", "end"]
```

## 処理の仕様

1. `try`の最初で`"start"`を追加する
2. `JSON.parse(jsonText)`で解析する
3. 成功したら`"success"`を追加し、解析結果をreturnする
4. 失敗したら`catch`で`"error: エラー名"`を追加し、`null`をreturnする
5. 成功・失敗のどちらでも、`finally`で`"end"`を追加する

## ルール

- `try/catch/finally`をすべて使う
- `finally`から値をreturnしない
- `JSON.parse()`は`try`内で呼ぶ
- `logs`には`push()`で文字列を追加する
- 関数を名前付きexportする
