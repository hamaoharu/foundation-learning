# Unit 15 / Q001：エラーの原因を特定する

## 問題

次のコードは実行時にエラーになります。コードを実行せず、エラー情報とコードを読んで答えてください。

```js
function formatUserName(user) {
  return user.profile.name.trim();
}

const user = {
  id: 1,
  profile: undefined,
};

console.log(formatUserName(user));
```

表示されたエラー：

```text
TypeError: Cannot read properties of undefined (reading 'name')
    at formatUserName (app.mjs:2:23)
    at app.mjs:10:13
```

## 問1

エラーの種類は何ですか。

## 問3
