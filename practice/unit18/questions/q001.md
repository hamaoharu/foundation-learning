# Unit 18 / Q001：同期処理・microtask・taskの順番

## 問題

次のコードを実行せずに読み、問1〜問4へ答えてください。

```js
console.log("A");

setTimeout(() => {
  console.log("B");
}, 0);

Promise.resolve().then(() => {
  console.log("C");
});

console.log("D");
```

## 問1

表示される内容を、実際の順番ですべて書いてください。

## 問2

同期処理として実行される`console.log()`はどれですか。

## 問3

microtaskとして待機するcallbackはどれですか。

## 問4

`setTimeout(..., 0)`の`"B"`が最後になる理由を書いてください。
