# Unit 18 / Q002：`await`後の実行順

次のコードは、コンソールにどの順番で文字を表示しますか。

```js
async function run() {
  console.log("B");
  await Promise.resolve();
  console.log("C");
}

console.log("A");
run();
console.log("D");
```

## 問題

1. 出力順を、文字だけで答えてください。
2. `run()`を呼び出したとき、`B`は同期的に表示されますか。
3. `run`関数はどこで一度中断しますか。
4. `C`が`D`より後に表示される理由を、`await`とmicrotaskを使って説明してください。

コードを実行せずに回答してください。
