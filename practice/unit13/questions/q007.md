# Unit 13 / Q007：クラスメソッドの共有を読む

## 問題

次のコードを**実行せずに**読み、問1〜問4へ回答してください。

```js
class User {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Hello, ${this.name}`;
  }
}

const haru = new User("Haru");
const aki = new User("Aki");

console.log(haru.name);                         // ①
console.log(haru.greet());                      // ②
console.log(haru.greet === aki.greet);          // ③
console.log(Object.hasOwn(haru, "greet"));      // ④
console.log(Object.hasOwn(User.prototype, "greet")); // ⑤
```

## 問1

①と②に表示される値を書いてください。

## 問2

③には`true`と`false`のどちらが表示されますか。

## 問3

④と⑤には、それぞれ`true`と`false`のどちらが表示されますか。

`Object.hasOwn(object, key)`は、指定したプロパティがそのオブジェクト自身に直接存在するかを確認します。

## 問4

③〜⑤の結果から、`greet`メソッドがどこに置かれ、どのように利用されているか説明してください。

## 考えるポイント

```text
haru自身
├─ name: "Haru"
└─ greetは直接持っていない
       ↓ 探す
User.prototype
└─ greetメソッド
```

`aki`も同じ`User.prototype.greet`を利用します。
