# Unit 13 / Q002：呼び出し方による`this`の違いを読む

## 問題

次のコードを**実行せずに**読み、問1〜問3へ回答してください。

```js
"use strict";

const user = {
  name: "Haru",
  getName() {
    return this.name;
  },
};

const aki = {
  name: "Aki",
  getName: user.getName,
};

console.log(user.getName()); // ①
console.log(aki.getName());  // ②

const getName = user.getName;
console.log(getName());      // ③
```

## 問1

①に表示される値を書いてください。

## 問2

②に表示される値を書いてください。

## 問3

③では値が表示されますか、それともエラーになりますか。理由も書いてください。

## 考えるポイント

```text
user.getName()
→ ドットの左側はuser

aki.getName()
→ ドットの左側はaki

getName()
→ オブジェクトのメソッドとして呼んでいない
```

`"use strict"`では、通常関数を単独で呼び出した場合の`this`は`undefined`です。
