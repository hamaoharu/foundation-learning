# Unit 13 / Q003：メソッド内の`map()`で`this`を使う

## 問題

次の`course`オブジェクトの`getLessonLabels`メソッドを実装してください。

`lessons`の各要素を、`"prefix: lesson"`形式へ変換した新しい配列を返します。

## 回答対象

```js
const course = {
  prefix: "Lesson",
  lessons: ["HTML", "CSS", "JavaScript"],
  getLessonLabels() {
    // ここに実装
  },
};
```

## 期待結果

```js
course.getLessonLabels();
// [
//   "Lesson: HTML",
//   "Lesson: CSS",
//   "Lesson: JavaScript",
// ]
```

## ルール

- `this.lessons`を使う
- `map()`を使う
- `map()`のコールバックはアロー関数で書く
- コールバック内で`this.prefix`を使う
- 元の`lessons`配列を変更しない

## 関数の役割

```text
getLessonLabels() {}
→ courseのメソッド
→ thisはcourse

(lesson) => {}
→ mapが各要素について呼ぶコールバック
→ 独自のthisを作らず、外側のthisを使う
```

## 累積復習

- `map()`
- アロー関数
- テンプレートリテラル
- メソッドの戻り値
- 元配列を変更しない処理
