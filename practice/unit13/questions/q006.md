# Unit 13 / Q006：クラスを継承する

## 問題

既存の`User`クラスを継承した`AdminUser`クラスを実装してください。

`AdminUser`は、親クラスの`name`と`role`に加えて、権限文字列の配列`permissions`を持ちます。

さらに、`"users:write"`権限を持っているか返す`canManageUsers()`メソッドを実装してください。

## 回答対象

```js
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  getIntroduction() {
    return `${this.name} (${this.role})`;
  }
}

class AdminUser extends User {
  // ここに実装
}
```

## 期待する使い方

```js
const admin = new AdminUser(
  "Haru",
  "admin",
  ["users:read", "users:write"],
);

admin.name;
// "Haru"

admin.role;
// "admin"

admin.permissions;
// ["users:read", "users:write"]

admin.getIntroduction();
// "Haru (admin)"

admin.canManageUsers();
// true
```

権限を持たない場合：

```js
const viewer = new AdminUser(
  "Aki",
  "viewer",
  ["users:read"],
);

viewer.canManageUsers();
// false
```

## ルール

- `class AdminUser extends User`を使う
- `constructor(name, role, permissions)`を定義する
- `this`を使う前に`super(name, role)`を呼ぶ
- `this.permissions`へ配列を保存する
- `canManageUsers()`では`includes()`を使う
- 親クラスの`getIntroduction()`を再定義しない

## 骨組み

```js
class AdminUser extends User {
  constructor(name, role, permissions) {
    // 親のconstructorを呼ぶ
    // permissionsを保存する
  }

  canManageUsers() {
    // users:writeが含まれるか返す
  }
}
```
