# Unit 13 / Q005：ユーザークラスを実装する

## 問題

名前`name`と役割`role`を持つ`User`クラスを実装してください。

インスタンスには、自己紹介文字列を返す`getIntroduction`メソッドを持たせます。

## 期待する使い方

```js
const haru = new User("Haru", "frontend");
const aki = new User("Aki", "designer");

haru.name;
// "Haru"

haru.role;
// "frontend"

haru.getIntroduction();
// "Haru (frontend)"

aki.getIntroduction();
// "Aki (designer)"
```

## ルール

- `class User`構文を使う
- `constructor(name, role)`を定義する
- `constructor`内で`this.name`と`this.role`へ値を保存する
- `getIntroduction()`をインスタンスメソッドとして定義する
- メソッド内で`this.name`と`this.role`を使う
- テンプレートリテラルを使う

## 骨組み

```js
class User {
  constructor(name, role) {
    // インスタンスへ保存
  }

  getIntroduction() {
    // 文字列を返す
  }
}
```

## 考えるポイント

```js
const haru = new User("Haru", "frontend");
```

この呼び出しでは、`constructor`内の値は次のようになります。

```text
this → 新しく作られるharuインスタンス
name → "Haru"
role → "frontend"
```
