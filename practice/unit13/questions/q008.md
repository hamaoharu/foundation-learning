# Unit 13 / Q008：継承と`instanceof`を読む

## 問題

次のコードを**実行せずに**読み、問1〜問4へ回答してください。

```js
class User {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Hello, ${this.name}`;
  }
}

class AdminUser extends User {
  canManageUsers() {
    return true;
  }
}

const user = new User("Aki");
const admin = new AdminUser("Haru");

console.log(admin.name);                     // ①
console.log(admin.greet());                  // ②
console.log(admin.canManageUsers());         // ③
console.log(admin instanceof AdminUser);     // ④
console.log(admin instanceof User);          // ⑤
console.log(admin instanceof Object);        // ⑥
console.log(user instanceof AdminUser);      // ⑦
```

## 問1

①〜③に表示される値を書いてください。

## 問2

④〜⑦に表示される`true`または`false`を書いてください。

## 問3

`AdminUser`には`constructor`と`greet()`を直接書いていません。それでも`admin.name`と`admin.greet()`を利用できる理由を説明してください。

## 問4

なぜ`admin instanceof AdminUser`と`admin instanceof User`が両方`true`になるのか、継承とプロトタイプチェーンという言葉を使って説明してください。

## 考えるポイント

`AdminUser`は`User`を継承しています。

```text
admin
  ↓
AdminUser.prototype
  ↓
User.prototype
  ↓
Object.prototype
  ↓
null
```

`instanceof`は、このつながりの中に指定したクラスの`prototype`があるかを確認します。
