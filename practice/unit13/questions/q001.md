# Unit 13 / Q001：メソッドから自分のプロパティを使う

## 問題

次の`user`オブジェクトの`getIntroduction`メソッドを実装してください。

メソッドは、同じオブジェクトの`name`と`role`を`this`で参照し、次の文字列を返します。

```text
Haru (frontend)
```

## 回答対象

```js
const user = {
  name: "Haru",
  role: "frontend",
  getIntroduction() {
    // ここに実装
  },
};
```

## ルール

- メソッド構文をそのまま使う
- `this.name`と`this.role`を使う
- テンプレートリテラルを使う
- `user.name`のように変数名を直接参照しない
- `console.log()`ではなく文字列を`return`する

## 入出力例

```js
user.getIntroduction();
// "Haru (frontend)"
```

同じメソッドを別のオブジェクトで呼び出した場合、そのオブジェクトの値を使います。

```js
const anotherUser = {
  name: "Aki",
  role: "designer",
  getIntroduction: user.getIntroduction,
};

anotherUser.getIntroduction();
// "Aki (designer)"
```
