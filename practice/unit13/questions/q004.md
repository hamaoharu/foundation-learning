# Unit 13 / Q004：`bind()`で`this`を固定する

## 問題

次のコードでは、`user.getIntroduction`を変数へ取り出しています。

`user`を`this`として固定した新しい関数を`boundIntroduction`へ代入し、単独で呼び出しても正しい文字列を返せるようにしてください。

## 回答対象

```js
const user = {
  name: "Haru",
  role: "frontend",
  getIntroduction() {
    return `${this.name} (${this.role})`;
  },
};

const boundIntroduction = /* ここを実装 */;
```

## 期待結果

```js
boundIntroduction();
// "Haru (frontend)"
```

## ルール

- `bind()`を使う
- `user.getIntroduction()`をその場で実行しない
- `boundIntroduction`には文字列ではなく、新しい関数を入れる
- 元の`user`を変更しない

## 考えるポイント

```js
user.getIntroduction.bind(user)
```

`bind()`は元の関数をすぐ実行せず、指定した`this`を使う新しい関数を返します。

```text
user.getIntroduction
→ 関数そのもの

.bind(user)
→ thisをuserに固定した新しい関数
```
