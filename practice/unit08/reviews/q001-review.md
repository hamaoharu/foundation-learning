## 推奨する改善

現在の次の書き方は正しく動作する。

```js
return sum += order.amount;
```

ただし、`sum`へ再代入してから返す必要はないため、次のほうが「次のaccumulatorを返す」という意図が直接伝わる。

```js
return sum + order.amount;
```

これは必須修正ではなく、可読性の改善。
