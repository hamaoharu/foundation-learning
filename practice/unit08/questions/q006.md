# Unit 8 / Q006：注文をステータス別にグループ化する

## 問題

注文オブジェクトの配列`orders`を受け取り、`status`ごとに注文を分けたオブジェクトを返す`groupOrdersByStatus`を実装してください。

## ルール

- `reduce`を使う
- 初期値に空オブジェクトを指定する
- `status`の値を動的なキーとして使う
- 各キーの値は注文オブジェクトの配列にする
- `for`、`for...of`、`forEach`は使わない
- 元の配列と注文オブジェクトを変更しない
- コールバックからaccumulatorを返す

## 入出力例

```js
const orders = [
  { id: 1, status: "pending" },
  { id: 2, status: "shipped" },
  { id: 3, status: "pending" },
];

groupOrdersByStatus(orders);
// {
//   pending: [
//     { id: 1, status: "pending" },
//     { id: 3, status: "pending" },
//   ],
//   shipped: [
//     { id: 2, status: "shipped" },
//   ],
// }

groupOrdersByStatus([]);
// {}
```

## 考える順番

1. 現在の注文から`status`を取得する
2. そのキーの配列がまだなければ、空配列を作る
3. 対応する配列へ現在の注文を追加する
4. accumulatorを次へ返す

## 累積復習

- 動的キーのブラケット記法
- `undefined`の判定
- `push()`
- 空オブジェクトを初期値にする考え方
