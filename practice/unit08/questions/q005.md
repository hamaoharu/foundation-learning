# Unit 8 / Q005：商品を価格の高い順に並べ替える

## 問題

商品オブジェクトの配列`products`を受け取り、`price`が高い順に並べ替えた新しい配列を返す`sortProductsByPriceDescending`を実装してください。

## ルール

- `sort`を使う
- `price`プロパティを比較する比較関数を書く
- `slice()`で元配列をコピーしてから並べ替える
- 元の配列と商品オブジェクトを変更しない
- `toSorted`は使わない

## 入出力例

```js
const products = [
  { id: 1, name: "Keyboard", price: 5000 },
  { id: 2, name: "Mouse", price: 3000 },
  { id: 3, name: "Monitor", price: 20000 },
];

sortProductsByPriceDescending(products);
// [
//   { id: 3, name: "Monitor", price: 20000 },
//   { id: 1, name: "Keyboard", price: 5000 },
//   { id: 2, name: "Mouse", price: 3000 },
// ]

products;
// 元の順番のまま
```

## 考えるポイント

- Q004の昇順と引き算の向きを反対にする
- 比較するのはオブジェクトそのものではなく、各商品の`price`
- 配列は新しくするが、中の商品オブジェクトは同じものを並べ替えてよい
