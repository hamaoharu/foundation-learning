# Unit 8 / Q002：ステータス別の件数を集計する

## 問題

ステータス名の文字列配列`statuses`を受け取り、各ステータスが何回登場したかを表すオブジェクトを返す`countStatuses`を実装してください。

## ルール

- `reduce`を使う
- 初期値に空オブジェクトを指定する
- 動的なキーにはブラケット記法を使う
- `for`、`for...of`、`forEach`は使わない
- 元の配列を変更しない
- コールバックからaccumulatorを返す

## 入出力例

```js
countStatuses(["todo", "done", "todo", "doing", "done", "todo"]);
// { todo: 3, done: 2, doing: 1 }

countStatuses(["done"]);
// { done: 1 }

countStatuses([]);
// {}
```

## 考えるポイント

- 初めて登場したステータスの現在件数は`undefined`
- `undefined`を`0`として扱い、1増やす
- 更新したオブジェクトを次の処理へ返す

## 累積復習

- `??`によるデフォルト値
- ブラケット記法
- オブジェクトのプロパティ更新
- 空配列の結果を初期値で表す考え方
