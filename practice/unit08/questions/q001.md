# Unit 8 / Q001：注文金額の合計を求める

## 問題

注文オブジェクトの配列`orders`を受け取り、すべての`amount`の合計を返す`calculateTotalAmount`を実装してください。

## ルール

- `reduce`を使う
- 初期値を明示する
- `for`、`for...of`、`forEach`は使わない
- 元の配列と注文オブジェクトを変更しない
- コールバック内で波括弧と`return`を明示する

## 入出力例

```js
calculateTotalAmount([
  { id: 1, amount: 1200 },
  { id: 2, amount: 800 },
  { id: 3, amount: 3000 },
]);
// 5000

calculateTotalAmount([]);
// 0
```

## 考えるポイント

- 初期値は、要素を1つも処理していない時点の合計
- コールバックから返した値が、次の処理のaccumulatorになる
- `reduce`全体の戻り値は最後のaccumulator
