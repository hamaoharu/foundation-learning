# Unit 8 / Q004：数値を昇順に並べ替える

## 問題

数値配列`numbers`を受け取り、小さい順に並べ替えた新しい配列を返す`sortNumbersAscending`を実装してください。

## ルール

- `sort`を使う
- 数値用の比較関数を書く
- `slice()`で元配列をコピーしてから並べ替える
- 元配列を変更しない
- `toSorted`は使わない

## 入出力例

```js
const original = [30, 5, 100, -2, 5];

sortNumbersAscending(original);
// [-2, 5, 5, 30, 100]

original;
// [30, 5, 100, -2, 5]

sortNumbersAscending([]);
// []
```

## 考えるポイント

- 比較関数なしの`sort()`は数値を文字列として比較する
- 昇順の比較関数は、2つの値の差をどちらの順番で返すか
- `sort()`を呼び出した配列自体が変更される

## 累積復習

- `slice()`による配列コピー
- 元配列と新しい配列の違い
- コールバックの`return`
