# Unit 8 / Q003：商品カテゴリ別の件数を集計する

## 問題

商品オブジェクトの配列`products`を受け取り、`category`ごとの商品数を表すオブジェクトを返す`countProductsByCategory`を実装してください。

## ルール

- `reduce`を使う
- 初期値に空オブジェクトを指定する
- `category`の値を動的なキーとして使う
- `for`、`for...of`、`forEach`は使わない
- 元の配列と商品オブジェクトを変更しない
- コールバックからaccumulatorを返す
- まずQ002の回答を見ずに書いてみる

## 入出力例

```js
countProductsByCategory([
  { id: 1, category: "device" },
  { id: 2, category: "book" },
  { id: 3, category: "device" },
  { id: 4, category: "food" },
  { id: 5, category: "device" },
]);
// { device: 3, book: 1, food: 1 }

countProductsByCategory([]);
// {}
```

## 考える順番

1. accumulatorの初期値は何か
2. 現在処理中の商品のカテゴリ名を取得する
3. そのカテゴリの現在件数を取得する
4. 件数を1増やす
5. accumulatorを次へ返す
