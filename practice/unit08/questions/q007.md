# Unit 8 / Q007：初見総合—商品価格を集計して並べ替える

## 問題

商品オブジェクトの配列`products`を受け取り、次の形の新しいオブジェクトを返す`createPriceSummary`を実装してください。

```js
{
  totalPrice: すべての商品のprice合計,
  sortedProducts: priceが安い順に並べた新しい配列,
}
```

## ルール

- `totalPrice`は`reduce`で求める
- `reduce`の初期値を明示する
- `sortedProducts`は`slice()`でコピーしてから`sort()`する
- 数値用の比較関数を書く
- `for`、`for...of`、`forEach`は使わない
- 元の配列と商品オブジェクトを変更しない
- 各コールバックで波括弧と`return`を明示する
- まず資料と過去の回答を見ずに実装する

## 入出力例

```js
const products = [
  { id: 1, name: "Keyboard", price: 5000 },
  { id: 2, name: "Mouse", price: 3000 },
  { id: 3, name: "Monitor", price: 20000 },
];

createPriceSummary(products);
// {
//   totalPrice: 28000,
//   sortedProducts: [
//     { id: 2, name: "Mouse", price: 3000 },
//     { id: 1, name: "Keyboard", price: 5000 },
//     { id: 3, name: "Monitor", price: 20000 },
//   ],
// }

createPriceSummary([]);
// { totalPrice: 0, sortedProducts: [] }
```

## 完了判定

- `reduce`の数値accumulatorを自力で扱える
- 比較関数でオブジェクト配列を昇順にできる
- 破壊的な`sort`から元配列を守れる
- 複数の計算結果を新しいオブジェクトへまとめられる
