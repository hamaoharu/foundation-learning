# JavaScript 基礎学習プロジェクト

このプロジェクトは、JavaScript基礎カリキュラムに対する実力診断と、その結果に基づく学習記録を管理します。

## 進行段階

1. `diagnostic/` — 1問ずつ行う実力診断
2. `assessment/` — 診断完了後の単元別評価
3. `learning-plan/` — 評価完了後に確定する学習タスク
4. `practice/` — 学習タスク確定後の演習

STEP 1の実力診断、STEP 2の評価、STEP 3の学習計画作成まで完了しました。次は **STEP 4：Unit 1の演習** です。

- 最終評価：[`assessment/final-assessment.md`](./assessment/final-assessment.md)
- 学習計画：[`learning-plan/plan.md`](./learning-plan/plan.md)

## 診断ルール

- 原則として、検索・AI・書籍・既存コードを参照せず回答する
- 問題文で許可されない限り、コードを実行して出力を確認しない
- 分からない箇所も空欄にせず「分からない」と書く
- 推測した場合は、その旨を明記する
- 回答後にレビューを受けるまで問題ファイルは変更しない
- 各問題の評価後、必要に応じて確認問題を追加する

## 回答方法

各問題に対応する `answers/qXXX-answer.md` に回答を記入してください。チャットへ同じ内容を貼り付けても構いません。
